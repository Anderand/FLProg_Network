# Подключение проекта FLE4D-30MT

Импортируйте универсальный FLProg_WebUI_Start.ubi один раз. Добавьте один блок Web UI Start и задайте параметр «ID проекта»: `FLE4D-30MT` (без кавычек и расширения).

Блок подключит `FLE4D-30MT_webui.h`. При обновлении макета с тем же ID обновите пакет и пересоберите прошивку. Сеть и SPI задаются в проекте FLProg.
