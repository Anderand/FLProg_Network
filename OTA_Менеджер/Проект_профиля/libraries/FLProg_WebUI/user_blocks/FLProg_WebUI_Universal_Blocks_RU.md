# FLProg Web UI — универсальные блоки

Комплект содержит восемь пользовательских блоков для FLProg:

- Publish Bool / Int / Float / Text;
- Command Bool / Int / Float / Text.

Все блоки используют `CHANNEL` как стабильный числовой номер канала из descriptor
проекта. Это сохраняет FBD-схему при изменении надписей, страниц и размещения
виджетов в редакторе.

Для каждого блока: импортируйте нужный `.ubi` через импорт пользовательских
блоков FLProg. Блоки Publish имеют входы `EN`, `CHANNEL`, `VALUE`. Блоки
Command имеют входы `EN`, `CHANNEL` и выходы `NEW`, `VALUE`.

Системные каналы №0–100 обслуживаются библиотеками автоматически. Их не нужно
подключать через Publish/Command. Пользовательские каналы занимают №101–255.
Точные номера вашего проекта смотрите в редакторе по кнопке **«Каналы FLProg»**
или в `CHANNELS_RU.md` рядом с собранной библиотекой проекта. Не используйте
порядковую позицию в массиве каналов вместо номера CHANNEL.

Например, если уставке назначен номер 101, `Command Float` получает
`CHANNEL = 101`. Для двустороннего канала `Publish Float` с тем же номером
возвращает фактическое значение из FBD в веб. Выход `NEW` означает приём новой
команды; выполнение подтверждается отдельными каналами busy/result.

`FLProg_WebUI_Universal_Blocks.ubl` — единая библиотека: импортируйте её
через FLProg, и все блоки появятся в одной папке `FLProg Web UI`. Отдельные
`.ubi` оставлены для точечного импорта и отладки.
