# Менеджер STM32 OTA 0.7.13 — FLE4D-30MT

Комплект для передачи: готовый Windows EXE и актуальный профиль FLE4D-30MT
с программой **1.0.4-PROFILE**, подготовленной из скетча `3.ino`.
Цель: STM32F407VG, Flash 1 МиБ, W5500.
Проверены компиляция, совместимость, адреса, размеры и SHA-256.
**Версия 1.0.4 на контроллере ещё не испытывалась.** Ранее на нашем FLE4D
проверена предыдущая 1.0.3; не считать её испытания проверкой новой сборки.

## Запуск и прошивка по OTA

1. Полностью распакуйте архив в доступную для записи папку.
2. Запустите `FLProg_STM32_OTA_Manager.exe`. Python для запуска не нужен.
3. Откройте «Поиск OTA», укажите подсеть своей сети и нажмите «Найти OTA».
   Выберите именно свой FLE4D-30MT и нажмите «Использовать выбранный IP».
   Либо введите его адрес на вкладке «Прошивка» вручную.
4. Профиль **FLE4D-30MT — программа профиля 1.0.4** уже выбран по умолчанию.
5. Нажмите **«Программа профиля»**. Поле BIN очистится, а под ним будет
   явно показано использование программы профиля (363280 байт).
   Нужный файл уже находится в `profiles\fle4d_30mt_profile_1_0_4\application.bin`;
   дополнительно выбирать его вручную не требуется.
6. Если текущий OTA-пароль пустой, оставьте поле пароля пустым. Если установлен
   другой пароль, укажите пароль текущей программы на устройстве.
7. Нажмите **«Прошить по OTA»**, дождитесь результата и перезапуска.
   Затем снова найдите устройство: DHCP-адрес после смены программы может измениться.

«Проверить OTA-порт» проверяет только соединение, прошивку не отправляет.
В поле «Прошивка ПЛК (BIN)» нужен **application.bin**, а не bootloader.bin.
Новые собственные BIN должны быть собраны под FLE4D с адресом **0x08010000**;
обычная сборка Arduino с 0x08000000 для OTA не подходит.
Для OTA не нужны Arduino IDE, Python и ST-Link, если загрузчик и OTA-программа
уже установлены на целевом контроллере.

## Первая установка

Если в ПЛК ещё нет совместимого загрузчика и OTA-программы, используйте
«Первичная установка по SWD»: нужны ST-Link и установленный STM32CubeProgrammer.
Укажите путь к `STM32_Programmer_CLI.exe`. Эта операция пишет оба образа.
Кнопка «Перезапуск по SWD» требует ST-Link и не является сетевым reset.
Последующие OTA-обновления пишут приложение и staging, сохраняя загрузчик.
STM32CubeProgrammer и драйвер ST-Link в этот комплект не включены.

## Программа профиля

Веб открывается по HTTP-адресу контроллера. Вкладки:
**Главная → Диагностика → Входы → Выходы**.
На Главной — дополнительные параметры RT_HW, версии библиотек, диспетчер
и интерфейсы проекта. Ethernet-блок DNS/status/error убран. Текстовые
поля интерфейсов имеют H=1, W=6.

Входы: 16 DI и 4 AI ADS1115. Выходы: 14 DO и 2 AO.
Для управления откройте «Выходы» и включите **«Управление DO/AO из веба»**.
Веб становится источником команд с нулевыми начальными заданиями.
При выключении переключателя снова работает исходная логика ПЛК.
Режим хранится только в RAM и выключен после перезапуска.
AO ограничены 0…10000 мВ. Readback показывает программный сигнал DO
и задание AO; напряжение/ток на клеммах отдельно не измеряются.
Задания не сбрасываются автоматически только от закрытия браузера.

SPI0: PB13/PB14/PB15, CS PB12; Ethernet DHCP; OTA TCP 3233;
пароль новой программы пустой; MAC из скетча `78:AC:C0:5C:44:8D`.
Для нескольких одновременно подключённых контроллеров задайте уникальные
MAC в их проектах перед сборкой. Исходник 3 использует сигнатуру EEPROM 245:
при несовпадении сигнатуры применяются начальные настройки исходного проекта.

## Состав

- EXE менеджера — готов к запуску после распаковки.
- `profiles` — только целевой профиль с загрузчиком, приложением и паспортом.
- `Проект_профиля` — рабочий .ino, макет .flpui, библиотеки проекта и карта каналов.
- `build_tools` — локальная сборка из программы, без заранее записанных личных путей.
- `ПРОВЕРКА.md`, `MANIFEST_SHA256.json` — результаты проверки и хеши файлов.

Для пересборки нужна Arduino IDE из FLProg со **STM32 core 3.0.0** и
штатными библиотеками исходного FLProg-проекта. Укажите .ino и папку
`Проект_профиля\libraries` на вкладке «Плата и сборка»; проверка покажет
недостающие зависимости. Установщик библиотек и BAT-файлы не поставляются.
Сохраняйте весь комплект целиком; переносить только EXE недостаточно.
IP, пути к скетчу, пароли и `settings.json` отправителя не включены.


## Остальные платы общего комплекта r15

Сохранены 20 ранее собранных загрузчиков и loader-only профилей.
По умолчанию они скрыты; включите «Показать непроверенные платы и профили».
Для них требуется собственный BIN проекта и аппаратная проверка платы.
FLE4D 1.0.4 остаётся выбран по умолчанию, при старте IP/пароль пустые.
