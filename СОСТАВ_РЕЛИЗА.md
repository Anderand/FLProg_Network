# Состав передачи r18 — 14.11.2026

[Релиз GitHub](https://github.com/Anderand/FLProg_Network/releases/tag/v2026.11.14-r18) содержит два ZIP и их файлы SHA-256.

## Библиотека Network

`FLProg_Network_dev20_r18_2026-11-14.zip` содержит корневую папку `FLProg_Network`: src, library.properties, keywords.txt, пользовательские блоки, документацию, тесты и манифест файлов. Версия dev20, API 10006. Закройте IDE, замените установленную папку FLProg_Network и пересоберите проект. Штатные RT_HW и Flprog_Utilites устанавливаются отдельно и этим архивом не заменяются.

## Редактор и WebUI

`FLProg_WebUI_Editor_transfer_2026-11-14.zip` содержит корневую папку `FLProg_WebUI_Editor`:

- `Editor/FLProg_WebUI_Editor/FLProg_WebUI_Editor.exe` и `_internal` — готовая программа; сохраняйте их вместе.
- `Source/flprog_webui_next` — исходники, генераторы, runtime, тесты, проекты и документация текущего редактора.
- `Libraries/FLProg_WebUI` — устанавливаемая библиотека и пользовательские блоки.
- `Source/legacy_web_ui_designer` — исторический прототип для справки.
- `Checks` и `MANIFEST_SHA256.json` — результаты проверки и контрольные суммы.

Сетевую библиотеку устанавливайте из первого архива. Python для запуска EXE не требуется. Перед сборкой проекта выберите локальную папку вывода; при необходимости задайте FLPROG_LIBRARIES. [Подробная инструкция](Редактор/ПЕРЕДАЧА_2026-11-14.md).

## Исходники в Git

Network — `Библиотека/FLProg_Network`; WebUI runtime — `Библиотека/FLProg_WebUI`; текущий редактор — `Исходники/WebUI`; прототип — `Исходники/WebUI_legacy`. В каталоге `API_для_интеграции` находятся синхронизированные копии публичных контрактов. Исторические материалы и прошивки прежних релизов сохранены.

Проверки без устройства и их ограничения перечислены в [отчёте r18](Проверки/RELEASE_R18/README.md).
