# СОСТАВ РЕЛИЗА

FLProg Network — полный состав 24.10.2026

БИБЛИОТЕКИ (копируются вручную)
FLProg_Network — актуальная сетевая библиотека.
FLProg_WebUI — runtime редактора.
Flprog_Modbus — исправленная рабочая копия из IDE.
Источник библиотек: C:\F-981\FLProg\ideV8\portable\sketchbook\libraries.
Личные Wi-Fi параметры демонстрационного MQTT-скетча заменены шаблонами.

БЛОКИ_FLPROG
OTA — версия 0.4; W5500_Diagnostic; MQTT — 3 блока; WebUI — 8 блоков и UBL.
Проектные Configure-блоки WebUI генерируются редактором для конкретного проекта.

РЕДАКТОР
Готовый EXE, BAT запуска, DLL, runtime, генератор, API-каталог, два демопроекта.
Исходники редактора: Исходники/WebUI.

OTA_МЕНЕДЖЕР
Переносимый EXE 0.7.7, 21 профиль, 20 загрузчиков, каталог и инструменты сборки.
Готовое тестовое приложение FLE4D 1.0.1. Для остальных плат BIN создаётся из проекта пользователя.

ПРИМЕРЫ И ИСХОДНИКИ
Примеры/FLE4D_1.0.1: скетч, BIN, пакет, параметры платы.
Примеры библиотек находятся в их examples; прочие аппаратные примеры — в Исходники.
Исходники менеджера, сборщика, загрузчика, сканера и блоков включены.

ПРОВЕРКИ
Повторно выполнены разбор Python/XML, контракт OTA-блока, профили и хэши загрузчиков,
WebUI static verify, 5 тестов генератора, проверка синтаксиса JavaScript.
Результат: Проверки/COMPOSITION_VERIFICATION.json.
Запуск EXE редактора и сборка пакета подтверждены предыдущей проверкой этого релиза.
Новые аппаратные испытания и компиляция всех плат в этой проверке состава не выполнялись.
IDE, ядра плат и STM32CubeProgrammer устанавливаются отдельно; это не часть переносимого комплекта.
Старые версии, резервные копии, персональные проекты, build_env и промежуточные сборки исключены.

Менеджер 0.7.7: при запуске доступен только проверенный профиль FLE4D-30MT 1.0.1. Для остальных включите «Показать непроверенные платы и профили». Галочка по умолчанию выключена при каждом запуске. Каталог сборки других плат также скрыт до включения галочки. Старые OTA v1, диагностические TEST1/UART-first и 1.0.0 удалены из актуальной папки portable_v6.
