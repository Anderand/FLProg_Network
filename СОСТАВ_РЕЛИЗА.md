# Состав r6

Основной продукт — FLProg Network. В корне три библиотеки, редактор, OTA-менеджер,
блоки, примеры, исходники и документация. EXE программ находятся в своих папках.
Редактор 1.7.0 (r6), runtime с исправлениями, менеджер 0.7.7 без изменений.
Библиотеки: FLProg_Network, FLProg_WebUI, Flprog_Modbus.
Блоки: OTA 0.4, W5500 Diagnostic, MQTT, WebUI; конфигуратор проекта генерирует редактор.
Профилей менеджера 21, основных загрузчиков 20. Прежний проверенный профиль 1.0.1 сохранён.
Новая проверенная прошивка 1.0.7 находится в Примеры/FLE4D_WebUI_1.0.7.
В редакторе 4 чистых макета, включая fle4d_webui_test.flpui; персональные проекты исключены.
RT_HW_00_BASE, Flprog_Utilites, Wire, IDE, ядра и STM32CubeProgrammer в комплект не входят.
Нет установщиков библиотек, настроек пользователя, кэшей и промежуточных сборок.
Все файлы перечисляет MANIFEST_SHA256.json; подтверждённые проверки — Проверки/RELEASE_R4.md.

Runtime r6 совпадает с библиотекой проверенного теста 1.0.7; включены test_field_sync.py/js, FIELD_SYNC_RESULT.md, снимки до/после перезапуска. Предыдущие проверенные примеры 1.0.5 и 1.0.6 сохранены как исторические.
