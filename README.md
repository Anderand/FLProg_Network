# FLProg Network — r13

**[Скачать готовый комплект с EXE редактора и OTA-менеджера](https://github.com/Anderand/FLProg_Network/releases/download/v2026.10.25-r13/FLProg_Network_2026-10-25_r13.zip)** · [Релиз r13](https://github.com/Anderand/FLProg_Network/releases/tag/v2026.10.25-r13)

Общий комплект от 25.10.2026: три проектные библиотеки, блоки FLProg, переносимый Web UI редактор, OTA-менеджер 0.7.7 и проверенная прошивка **1.0.10-LOAD**. Редактор и менеджер входят в FLProg Network.

## Требование для STM32

**Требуется STM32 core 3.0.0** — пакет STMicroelectronics, используемый Arduino IDE/FLProg. На нём проверены FLE4D и BIN 1.0.10-LOAD. Core 2.7.1 не поддерживается: его IPAddress не содержит метода toString(). Arduino IDE 1.8.19 и STM32 core — разные версии компонентов.

Проверьте папку `<IDE>/portable/packages/STMicroelectronics/hardware/stm32/3.0.0` и путь ядра в логе компиляции. Если FLProg поставляется с 2.7.1, используйте комплект FLProg с ядром 3.0.0 или штатный порядок обновления пакета плат с сохранением пользовательских профилей. Не подменяйте отдельные файлы ядра и штатные Wire, RT_HW_00_BASE, Flprog_Utilites. Требование относится к STM32; ESP использует собственное ядро. Более новые ядра отдельно не проверены.

## Установка и запуск

1. Скачайте **FLProg_Network_2026-10-25_r13.zip** из Assets и распакуйте **целиком**. Кнопка Code → Download ZIP и автоматические Source code содержат исходники без готовых EXE.
2. Закройте FLProg и IDE. Вручную скопируйте **только три папки** из Библиотека: FLProg_Network, FLProg_WebUI, Flprog_Modbus — в `<IDE>/portable/sketchbook/libraries`, подтвердив замену их файлов. Перезапустите FLProg. [Подробная установка](Документация/УСТАНОВКА.md).
3. Импортируйте нужные .ubi/.ubl из Блоки_FLProg в пользовательскую библиотеку FLProg. Простое копирование Arduino-библиотек не импортирует блоки.
4. Редактор: **Редактор/FLProg_WebUI_Editor.exe** или **START_WEB_EDITOR.bat**. По умолчанию http://127.0.0.1:8766/. Python не нужен. Переносите всю папку с DLL, public, runtime и tools; один EXE отдельно не работает. Если порт занят старой копией, закройте её или запустите `FLProg_WebUI_Editor.exe 18826`.
5. Менеджер: **OTA_Менеджер/FLProg_STM32_OTA_Manager.exe** либо START_OTA_MANAGER.bat. Профили и загрузчики оставляйте рядом.

Установщиков библиотек нет. Штатные RT_HW_00_BASE, Flprog_Utilites, Wire и другие библиотеки не входят в этот комплект. SPI/Ethernet задаются проектом FLProg. FLProg_Network и FLProg_WebUI обновляйте вместе.

## Новое в r13

Загрузка веба показывает процент, повторяет только безопасные GET при временных ошибках и кеширует статические ресурсы по хешу содержимого. HTML и данные ПЛК остаются без кеша; команды POST автоматически не повторяются. Паузы 80 мс между скриптами убраны. Сохранены gzip, порционная выдача из Flash, уведомления, busy/result, состояния полей, проверка проекта и предпросмотр без ПЛК.

В тесте FLE4D: первое открытие 2.448 с, 15 повторных 0.979–1.765 с, 400 чтений ресурсов без ошибок, занятая куча 7108 байт в 293 замерах. 28 автотестов прошли. [Полный отчёт и ограничения](Документация/LOAD_RU.md). Один HTTP-клиент остаётся: отказ TCP до получения HTML не может быть исправлен JavaScript-повтором.

Новый EXE использует тот же runtime при сборке пакетов. Обновление EXE само по себе не обновляет веб на контроллере — требуется пересборка и загрузка приложения.

## Проверенная прошивка FLE4D

Файл **Примеры/FLE4D_1.0.10_LOAD/FLE4D_LOAD_1_0_10.bin**. В менеджере выберите проверенный профиль FLE4D-30MT и **явно выберите этот BIN**. Приложение внутри старого профиля не подменено автоматически. Существующий OTA-загрузчик менять не нужно; адрес приложения **0x08010000**. BIN не предназначен для записи по 0x08000000. Пароль теста пустой, адрес выдан DHCP.

Аппаратная проверка: FLE4D-30MT / STM32F407VG / W5500 / UART6, core 3.0.0. Flash 135140, static RAM 16152, BIN 135628 байт; +40 RAM к 1.0.9 относится к mallinfo-диагностике. Физические выходы тест не переключает. Другие платы требуют отдельных испытаний; Windows 7 отдельно не проверялась.
