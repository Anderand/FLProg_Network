# FLProg Network — r16 + NTP TimeZones0.1 (29.10.2026)

Полный комплект: **FLProg_Network + FLProg_WebUI + Flprog_Modbus**,
блоки FLProg, Web-редактор с EXE, переносимый OTA-менеджер **0.7.13**.

**[Скачать готовый архив с EXE](https://github.com/Anderand/FLProg_Network/releases/tag/v2026.10.28-r16)**
— файл **FLProg_Network_2026-10-28_r16.zip**. Кнопка GitHub Code → Download ZIP
скачивает исходники; готовые программы находятся в Releases.

## Новое в main: NTP TimeZones0.1

Часовые пояса в минутах, летнее/зимнее время (ЕС/США и свои правила C++),
местная дата и признак DST. Старый UTC API сохранён.
[Инструкция](Документация/NTP_TIMEZONES_RU.md),
[Basic](Блоки_FLProg/NTP/Basic), [Professional](Блоки_FLProg/NTP/Professional),
[исходники и тесты](Исходники/NTP), [проверки](Проверки/NTP_TimeZones_v0.1).
12592 сравнений и контрольная сборка F407 прошли; аппаратный NTP ещё не испытывался.

**Архив r16 с EXE ниже пока не содержит это дополнение.** Для NTP возьмите
библиотеку и блоки из main (Code → Download ZIP). EXE менять не требуется.

## Быстрый запуск

1. Распакуйте полный архив целиком. Python для EXE не нужен.
2. Закройте FLProg/Arduino IDE. Вручную скопируйте только **FLProg_Network,
   FLProg_WebUI, Flprog_Modbus** из `Библиотека` в
   `<IDE>\portable\sketchbook\libraries`, заменяя файлы только этих библиотек.
   Штатные RT_HW_00_BASE, Flprog_Utilites, Wire не заменяйте. Установщика нет.
3. Для STM32 требуется **STM32 core 3.0.0**; 2.7.1 не поддерживается.
4. Импортируйте нужные UBI/UBL из `Блоки_FLProg` в пользовательскую библиотеку
   FLProg. SPI/Ethernet/Wi-Fi настраивайте в своём проекте FLProg.
5. Запустите `Редактор\FLProg_WebUI_Editor.exe`. Переносите всю папку
   вместе с `_internal`. По умолчанию http://127.0.0.1:8766/;
   при занятом порте передайте EXE номер другого порта первым аргументом.
6. Для прошивки запустите `OTA_Менеджер\FLProg_STM32_OTA_Manager.exe`.
   Рядом должны оставаться `profiles` и `build_tools`.

## Новое в r16

- MQTT в простое обслуживается раз в 10 мс, во время обмена — раз в 1 мс,
  порциями до 64 байт. Настройка POLL_MS добавлена в Core.
- Блоки **[Basic](Блоки_FLProg/MQTT/Basic)** и
  **[Professional](Блоки_FLProg/MQTT/Professional)**: по три UBI, общая логика.
- Динамические подписки сохранены. Блоки надо вызывать каждый цикл:
  расписанием сокета занимается библиотека.
- [Отчёт сравнения](Документация/MQTT_PERFORMANCE_RU.md): меньше обращений
  MQTT к транспорту, Flash +384, статическая RAM +12 байт в одинаковом скетче F407;
  локальный массив чтения 64 байта на стеке. Аппаратный цикл ещё не измерен.

Редактор, менеджер, Web UI Start/OTA и готовые BIN сохранены из r15 без пересборки:
изменения относятся к MQTT-библиотеке и её блокам. Для применения нужна сборка
своего проекта с новой библиотекой. Указанные ниже возможности уже были в r15.

## Состав и предыдущие улучшения

- MQTT: снят предел четырёх подписок, память таблицы расширяется при добавлении
  фильтров. Новые блоки Core/Publish/Subscribe v0.3 (Basic и Professional), счётчики и диагностика RAM.
- Веб: объединены CSS/JS и описания виджетов, выдача потоком из Flash,
  исправлен затянувшийся экран «Чтение данных ПЛК» при позднем запросе.
  Аппаратный замер a123 на FLE4D: 29 → 6 запросов, медиана холодной загрузки
  15.389 → 2.840 с, статическая RAM 19392 байта без роста.
- Редактор: свежий EXE и исходники генератора, редактируемые ID и полный путь
  папки проекта, совместимость, проверка проекта и автономный предпросмотр.
- Менеджер 0.7.13: крупная кнопка «Прошить по OTA», понятный выбор BIN,
  Windows-пути, FLE4D-30MT в каталоге сборки и программа профиля 1.0.4.

## Проект и прошивка

Откройте .flpui в редакторе, задайте ID и папку проекта **вне IDE**,
проверьте совместимость и соберите пакет. Генератор создаёт
`<проект>\libraries\FLProg_WebUI_Project_<ID>\src\<ID>_webui.h`.
Единый профессиональный Web UI Start подключает проект по ID. Чтобы получить
ускоренный веб, старый пакет пересоберите новым редактором.

В менеджере: «Плата и сборка» → своя плата, .ino и его папка libraries →
проверка совместимости → «Собрать BIN». Это только сборка.
На главной выберите IP, пароль и **BIN приложения** → «Прошить по OTA».
Это приложение, собранное под OTA-разметку выбранной платы, а не загрузчик
и не обычный BIN IDE с адресом 0x08000000. Пустое поле BIN означает приложение
из профиля; кнопка «Программа профиля» возвращает этот режим и очищает поле.

По умолчанию в менеджере выбран FLE4D-30MT **1.0.4-PROFILE**:
программа профиля из скетча 3, четыре страницы, диагностика, DI/AI и DO/AO,
без блока Ethernet на Главной. Сборка проверена; **эта версия ещё не прошивалась
на плату**. Не выдаётся за аппаратно испытанную. Начальные DO/AO управляются
исходной программой; веб-управление включается отдельно, AO 0..10000 мВ.
Подробности и точные исходники находятся в `OTA_Менеджер\Проект_профиля`.
Из-за фиксированного MAC исходного примера нескольким ПЛК нужны разные MAC.

Аппаратно проверенный пример ускоренного веба **1.0.23-WIDGETS** лежит в
`Примеры\FLE4D_1.0.23_WIDGETS`. Он не подменяет программу профиля.
Оба приложения предназначены для FLE4D-30MT / STM32F407VG / W5500, Flash 1 МиБ,
с совместимым загрузчиком и адресом приложения **0x08010000**.
Точные библиотеки, с которыми собран каждый сохранённый BIN, лежат рядом
с его скетчем. Новая общая MQTT находится в корневой `Библиотека`;
уже готовые BIN автоматически от замены библиотеки не изменяются.
