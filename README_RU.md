## Установка и запуск

1. Распакуйте **FLProg_Network_2026-10-25_r12.zip** целиком.
2. Закройте FLProg и IDE. Вручную скопируйте из **Библиотека** папки
   **FLProg_Network**, **FLProg_WebUI**, **Flprog_Modbus** в
   `<IDE>/portable/sketchbook/libraries`. Например, IDE находится в
   `C:\F-981\FLProg\ideV8`. Заново откройте FLProg.
3. Нужные блоки импортируйте из **Блоки_FLProg** в пользовательскую библиотеку FLProg.
4. Запустите **Редактор/FLProg_WebUI_Editor.exe** или **START_WEB_EDITOR.bat**.
   Откроется http://127.0.0.1:8766/. Python не нужен; переносите всю папку Редактор.
   Если старая копия заняла порт, закройте её или запустите EXE с другим портом:
   `FLProg_WebUI_Editor.exe 18825`.
5. OTA-менеджер: **OTA_Менеджер/FLProg_STM32_OTA_Manager.exe** либо **START_OTA_MANAGER.bat**.

Установка библиотек только ручная. SPI/Ethernet задаются проектом FLProg.
FLProg_Network и FLProg_WebUI обновляйте вместе из этого комплекта.

## Новое в r11

Уведомления различают **«Отправлено»**, **«Принято контроллером»** и
**«Подтверждено данными»**. Старый result=true не подтверждает новую команду.
Отмена и ошибки показываются отдельно; при неизвестном результате
автоматического повтора нет. Пароли не выводятся, карточек до пяти.
[Поведение и отчёт](Документация/NOTIFICATIONS_RU.md).

Flash новой тестовой сборки 133840 байт, статическая RAM 16112 байт.
Gzip и порционная Flash-выдача сохранены; буфер HTTP не увеличен.
Gzip включается при компиляции флагом FLPROG_WEBUI_GZIP_ASSETS=1,
в проверенном BIN он уже включён.

## Проверенная прошивка FLE4D

[Примеры/FLE4D_1.0.9_NOTICES](Примеры/FLE4D_1.0.9_NOTICES/README.md) содержит
**FLE4D_NOTICES_1_0_9.bin**, скетч, исходные команды сборки и протоколы испытаний.
В менеджере выберите проверенный профиль FLE4D-30MT, затем **вручную выберите этот BIN**.
Приложение внутри профиля менеджера осталось прежним и не является тестом 1.0.9.
Перед отправкой проверьте имя файла в логе.

Для испытанного контроллера: 192.168.100.8, OTA TCP 3233, пароль пустой.
Приложение рассчитано на 0x08010000. Уже установленный OTA-загрузчик менять не нужно.
Обычный BIN **не содержит стресс-массивов**. Отдельный стресс-BIN в папке
Стресс_тест — только материал испытаний. Старые прошивки оставлены как история.
Новый EXE редактора сам не обновляет ПЛК; для своих проектов нужна пересборка прошивки.

## Возможности редактора

Поля с состояниями и черновиками, группы, статус связи, подтверждение команд,
busy/result, синхронизация после перезапуска, проверка проекта с переходом
к виджету, локальный предпросмотр и кнопка **«Демо: уставка и busy/result»**.
Предпросмотр не исполняет FBD и не подключается к контроллеру.
