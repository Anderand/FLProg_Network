FLE4D-30MT — тест блока FLProg OTA v0.4, версия 1.0.1

Скетч использует FLProgOtaUniversalBlock. Код setup/loop блока взят
непосредственно из файла FLProg_OTA_Universal.ubi, а не заменён прямым
вызовом OTA-сервиса. Импорт в интерфейс FLProg этим не проверяется.

Входы: EN=true, NET_NUM=1, PASSWORD="", VERSION="1.0.1".
Модель из профиля сборки: FLE4D-30MT / STM32F407VG.
Настройка сети вынесена в тестовый скетч; блок её не изменяет.
W5500: PB13 SCK, PB14 MISO, PB15 MOSI, PB12 CS, шина RT_HW 0.
MAC сохранён из рабочего теста; DHCP включён. Ожидаемый IP 192.168.100.8,
но фактический адрес назначает DHCP-сервер.
UART6: PC6 TX, PC7 RX, 115200. OTA TCP 3233, пароль пустой.

После OTA-загрузки дождитесь автоматического перезапуска.
В UART появятся FIRMWARE VERSION: 1.0.1 и MODEL: FLE4D-30MT / STM32F407VG.
После получения IP ожидаются SUPPORTED=1 READY=1 BUSY=0 FAULT=0 ERR=0.
В сканере должна появиться версия 1.0.1.

Приложение собрано для STM32F407VG 1 MiB с адресом 0x08010000.
Совместимо с уже установленным загрузчиком FLE4D OTA.
BIN отправляется кнопкой «Обновить по OTA». Загрузчик повторно записывать не надо.
Файл .fwpkg содержит тот же рабочий загрузчик и новое тестовое приложение.
Повторить сборку можно командой python build.py при наличии установленной IDE.
