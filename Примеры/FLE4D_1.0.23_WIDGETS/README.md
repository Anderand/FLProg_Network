# FLE4D-30MT: a123 1.0.23-WIDGETS

Готовый OTA BIN — FLE4D_A123_1.0.23_WIDGETS.bin, приложение 0x08010000.
Выберите его явно в OTA-менеджере и укажите текущий IP ПЛК. Пароль примера пустой.
Образ предназначен для FLE4D-30MT / STM32F407VG / W5500, Flash 1 МиБ,
с уже установленным совместимым OTA-загрузчиком. По адресу 0x08000000 его не записывать.

Для сборки выберите sketch/a123_widgets/a123_widgets.ino и папку libraries
этого примера. Для редактирования откройте a123.flpui в новом редакторе,
задайте свою папку проекта вне IDE и пересоберите пакет. Исходные настройки
SPI/Ethernet остаются в скетче/проекте FLProg. Это аппаратный пример для
указанной платы, не универсальная прошивка всех STM32.

Сравнение с 1.0.22: 29→6 запросов, медиана 15.389→2.840 с без кеша,
RAM 19392 байта без роста. Полный отчёт: ../../Документация/WIDGET_CATALOG_RU.md.
