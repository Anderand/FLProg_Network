# Подключение проекта a123

Импортируйте универсальный FLProg_WebUI_Start.ubi один раз. Добавьте один блок Web UI Start и задайте параметр «ID проекта»: `a123` (без кавычек и расширения).

Блок подключит `a123_webui.h`. При обновлении макета с тем же ID обновите пакет и пересоберите прошивку. Сеть и SPI задаются в проекте FLProg.
