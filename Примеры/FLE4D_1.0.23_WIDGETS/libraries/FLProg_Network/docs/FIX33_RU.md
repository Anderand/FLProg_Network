# dev.16-fix33 — исправления по результатам аудита

База: dev.16-fix32, принятая пользователем как main 24.09.2026.
FIX33 содержит следующие изменения:

- Запрещено поверхностное копирование TCP- и HTTP-серверов, владеющих динамической памятью и сетевыми регистрациями. Передавайте их по ссылке или указателю. Перемещение также не разрешено.
- Тайм-аут отсутствия прогресса действует и при буферизованной отправке HTTP-ответа. По истечении времени соединение закрывается. Ответ 408 получает отдельное окно отправки; уже переданный ответ не превращается в ошибку из-за позднего pool(). Значение setRequestTimeout(0) сохраняет отключение тайм-аута.
- Строки размеров chunks больше не расходуют суммарный лимит HTTP trailers. Ограничения длины отдельной строки и размера trailers сохранены.
- Ожидание MQTT CONNACK/SUBACK/PINGRESP отсчитывается от завершения отправки запроса. Входящие PUBLISH не продлевают ожидание подтверждения. Тайм-аут прогресса отправки сохраняет прежнее поведение.

FLPROG_NETWORK_API_LEVEL остаётся 10006. Сигнатуры рабочих методов и generated-код не изменены; попытки копирования серверов теперь дают ошибку компиляции.

Проверки выполняются в рабочем каталоге проекта audit: компиляционный пробник fix33_compile и локальный C++ harness с извлечёнными из исходников методами, управляемыми часами и имитацией TCP. Полный итог проверки находится в отчёте проекта FIX33_RESULT_RU.md.

Аппаратная регрессия FIX33 пока не выполнена. Отчёт STATUS_FIX32_PROMOTED_RU.md относится к предыдущей версии FIX32. Modbus и KaScada на устройстве в этом этапе не проверяются по решению пользователя.
