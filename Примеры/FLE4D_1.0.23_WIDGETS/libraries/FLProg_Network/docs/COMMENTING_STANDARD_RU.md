# Стандарт комментариев

Каждый исходный файл `src/**/*.h` и `src/**/*.cpp`, а также каждый исполняемый
пример, содержит два слоя комментариев: назначение/архитектурные заметки и
расширенный контракт сопровождения.

Расширенный контракт фиксирует владельца состояния, порядок вызовов,
cooperative lifecycle, profile/platform границы и случаи, когда изменение
требует отдельного compatibility или hardware gate.

Комментарии не повторяют код построчно и не заменяют API reference. При
изменении поведения обновляют соответствующий языковой вариант в том же
изменении. Документы, `library.properties`, `keywords.txt` и изображения
являются данными, поэтому поддерживают заголовки, дату, статус и историю, а
не искусственные комментарии.
