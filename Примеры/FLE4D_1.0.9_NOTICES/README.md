# FLE4D 1.0.9-NOTICES

**FLE4D_NOTICES_1_0_9.bin** — проверенный BIN с уведомлениями.
В менеджере выберите проверенный профиль FLE4D-30MT, затем этот BIN вручную.
Приложение профиля не обновлено автоматически. Существующий OTA-загрузчик
менять не нужно; адрес приложения 0x08010000.

[Полный отчёт](../../Документация/NOTIFICATIONS_RU.md): отправка, приём,
подтверждение данными, отмена, ошибки, старый result=true и прокрутка карточек.
HTTP_VERIFICATION.json — проверка 19 ресурсов, DEVICE_STATE.json — итог ПЛК.
Снимки final_*.png показывают реальные испытания на FLE4D.

Flash 133840 байт, статическая RAM 16112 байт; BIN 134324 байта.
Пик всей кучи/стека отдельно не измерялся. Штатные библиотеки не включены.
Скетч меняет RAM, физические выходы не переключает.

Скетч находится в Скетч/FLE4D_NOTICES. Используйте библиотеки из корня
комплекта, штатные RT_HW_00_BASE, Flprog_Utilites и Wire из своей IDE,
профиль FLProg_FLE4D_30MT_OTA, STM32 core 3.0.0, -Os, offset 0x10000,
FLPROG_WEBUI_GZIP_ASSETS=1. Команды и лог сохранены рядом; пути в командах
относятся к машине испытаний и при переносе заменяются вашими путями.
Для разработки и полного набора тестов смотрите Исходники/WebUI/tools
в корне комплекта. tools здесь содержит отдельную проверку уведомлений.
