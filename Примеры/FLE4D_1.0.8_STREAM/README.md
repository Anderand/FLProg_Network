# FLE4D 1.0.8-STREAM — проверенный тест

**FLE4D_STREAM.bin** — финальная прошивка без больших стресс-массивов и тестового HTTP-переключателя.
В OTA-менеджере вручную выберите этот BIN. Приложение профиля менеджера осталось прежним.
Адрес приложения 0x08010000, существующий OTA-загрузчик менять не нужно.

| Показатель | Gzip r9 | 1.0.8-STREAM |
|---|---:|---:|
| Flash | 130856 | 131136 |
| Статическая RAM | 16112 | 16112 |
| HTTP ClientContext | 6120 | 6120 |
| BIN | 131340 | 131620 |

Контекст и RAM без роста; код +280 байт. Пик всей кучи/стека отдельно не измерялся.
[Полный отчёт испытаний](../../Документация/FLASH_STREAM_RU.md).

Скетч: Скетч/FLE4D_STREAM. Библиотеки FLProg_Network и FLProg_WebUI берутся из
корня комплекта; штатные RT_HW_00_BASE, Flprog_Utilites и Wire — из IDE.
Профиль FLProg_FLE4D_30MT_OTA, STM32 core 3.0.0, -Os, offset 0x10000,
FLPROG_WEBUI_GZIP_ASSETS=1. Исходные команды и лог сборки сохранены рядом:
пути машины испытаний при переносе заменяются вашими путями.

В Стресс_тест лежат отдельный диагностический BIN, массивы и только читающий
HTTP-тест фиксированного адреса 192.168.100.8. Это материалы испытаний,
не обычная прошивка. DEVICE_TEST.json фиксирует 128 КиБ, gzip, медленное чтение,
четыре RST, зависшего получателя и ответы OTA во время остановленного HTTP.
tools/host_test.py извлекает настоящие методы из библиотеки для C++-проверки;
путь к Zig/компилятору относится к машине испытаний и при переносе меняется.
