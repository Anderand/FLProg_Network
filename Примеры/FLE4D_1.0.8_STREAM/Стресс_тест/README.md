# Только стресс-тест

Эта прошивка содержит тестовые Flash-массивы. В финальной прошивке их нет. Проверка check_device.py выполняет только HTTP/OTA-идентификацию 192.168.100.8 и рассчитана на установленный стресс-BIN; на обычном BIN большой тестовый ресурс не доступен. Для восстановления обычного веба используйте FLE4D_STREAM.bin из корня комплекта.
