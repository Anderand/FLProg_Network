# Проверка команд через веб на FLE4D-30MT

24.10.2026. Реальный контроллер 192.168.100.8, прошивка **1.0.5-WEBUI1.7**.
Установлена по OTA с автоматическим перезапуском; ST-Link не использовался.

Все действия ниже выполнены через видимые элементы веб-страницы.

| Проверка | Наблюдаемый результат |
|---|---|
| Уставка 25 → 30.5, Enter | Подтверждён приём; применённая уставка стала 30.5 °C |
| Открыть подтверждение, «Отмена» | «Команда отменена»; счётчик 0, флаг false |
| Повторно открыть, «Отправить» | «Принято контроллером»; busy=true, result=false |
| Завершение примерно через 2 с | busy=false, result=true, счётчик 1, флаг true |
| Открытый диалог | Статус связи остаётся свежим; время работы продолжает обновляться |

Стандартный блокирующий window.confirm заменён HTML-диалогом внутри страницы.
Причина: он приостанавливал выполнение страницы и блокировал инструмент управления
встроенным браузером. Теперь есть обычные доступные кнопки «Отмена»/«Отправить»,
Escape отменяет; повторная отправка заблокирована на время подтверждения и запроса.
Свежесть связи повторно проверяется непосредственно перед отправкой.

Проверены синтаксис встроенного JS, сценарии команд test_runtime.py и ограничение
HTTP: ответ commandScript 1840 байт с заголовками, предел 2048, 14 маршрутов.
Компиляция: Flash 134616 байт, RAM 16112; BIN 135100 байт.

Проверены только демонстрационные значения RAM: физические выходы не переключались.
Оставлено: уставка 30.5, счётчик 1, тестовый флаг true. Отключение Ethernet в этой
проверке не выполнялось. GitHub и общий архив r3 не обновлялись.
Перед публикацией пересобрать комплект с исправлениями JSON, дополнительных связей
и новым диалогом. Новая проверенная тестовая прошивка — 1.0.5.
