# KC868-A16 RMII/LAN8720 — аппаратный результат

Дата: 14.10.2026.

## Конфигурация

- Контроллер: KinCony KC868-A16, ESP32.
- PHY: встроенный LAN8720, RMII.
- Настройки: PHY 0, MDC GPIO23, MDIO GPIO18, 50 MHz clock GPIO17 output.
- Адресация: DHCP.

## Результат первого gate

**PASS.** Контроллер получил адрес `192.168.100.12`; линк и RMII ready
стабильны, ошибок нет.

Лог:

```text
RMII ready=1 link=1 ip=192.168.100.12 error=0
```

## HTTP поверх RMII

**PASS.** Проверено с рабочей станции:

| URL | Результат |
| --- | --- |
| `http://192.168.100.12/` | HTTP 200, HTML diagnostics page, 761 B |
| `http://192.168.100.12/api/status` | HTTP 200, JSON 167 B |

Подтверждённые runtime-данные: gateway `192.168.100.1`, MAC
`20:43:A8:D1:34:B3`, speed `100 Mbps`, full duplex, error `0`.

## RMII link recovery

**PASS.** Кабель Ethernet был физически отключён на 10 секунд и подключён
обратно. После возврата выполнены шесть последовательных HTTP-запросов к
`/api/status`: все получили HTTP 200. На каждом ответе `ready:true`,
`link:true`, IP остался `192.168.100.12`, `error:0`.

## Следующие проверки

1. HTTP: открыть `/` и `/api/status` по полученному адресу.
2. Link recovery: отключить кабель, затем подключить обратно и подтвердить
   изменение `link` и восстановление HTTP.
3. TCP/UDP gate по RMII.
4. Совместный gate RMII + Wi-Fi STA и failover.
