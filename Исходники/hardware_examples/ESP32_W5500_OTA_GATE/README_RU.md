# ESP32 + W5500 OTA gate

Это отдельный аппаратный тест OTA через SPI W5500. Он использует публичные
route-aware TCP/UDP API `FLProg_Network` и совместим с `espota.py` ESP32 core
3.x. Это не тот же путь, что ArduinoOTA через lwIP для Wi-Fi/RMII.

1. Проверьте фактическое подключение W5500 и при необходимости задайте макросы
   CS/SCK/MISO/MOSI в начале скетча. Значения по умолчанию (`5/18/19/23`)
   подходят только для распространённого ESP32 DevKit и не универсальны.
2. Замените временный `FLPROG_W5500_OTA_PASSWORD` на отдельный пароль OTA.
3. В FLProg/Arduino выберите ESP32 с разметкой flash, содержащей две OTA app
   партиции, соберите и загрузите gate по USB.
4. В Serial Monitor дождитесь `W5500 ready=1`, назначенного IP и `OTA ready=1`.
5. Соберите бинарник целевого проекта и загрузите его утилитой ESP32 core:

   ```powershell
   python "<путь-к-esp32-core>\tools\espota.py" -i <IP_W5500> -p 3232 -a "<OTA-пароль>" -f "<путь-к-скетчу.bin>"
   ```

После успешной записи плата перезагрузится; проверяйте `starts`, `ends` и
`updateErrors` в Serial Monitor. Сначала используйте USB для восстановления,
если OTA-приложение или таблица разделов ещё не проверены. OTA W5500 пока
предназначена для ESP32; ArduinoOTA через встроенный RMII проверяется отдельным
gate `KC868_A16_RMII_OTA_GATE`.
