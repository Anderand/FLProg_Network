# KC868-A16 RMII TCP/UDP echo — аппаратный результат

Дата: 14.10.2026.

## Конфигурация

- Контроллер: KinCony KC868-A16, ESP32 + LAN8720 RMII.
- RMII: PHY 0, MDC GPIO23, MDIO GPIO18, clock GPIO17 output.
- DHCP IP: `192.168.100.12`.
- TCP echo port: `5001`.
- UDP echo port: `5002`.

## Результат

**PASS.** После прошивки gate HTTP-диагностика вернула:

```json
{"rmiiReady":true,"link":true,"ip":"192.168.100.12","error":0,
 "tcp":{"port":5001,"listening":true},"udp":{"port":5002}}
```

С рабочей станции выполнены реальные обмены:

| Проверка | Отправлено | Получено | Итог |
| --- | --- | --- | --- |
| TCP `:5001` | `flprog-tcp-rmii-2026` | та же строка | PASS |
| UDP `:5002` | `flprog-udp-rmii-2026` | та же строка | PASS |

После обмена `/api/status` показал: TCP `connections=1`, `rx=20`, `tx=20`;
UDP `packets=1`, `rx=20`, `tx=20`; RMII `ready=true`, `link=true`, `error=0`.

## Размер прошивки: UNIVERSAL против WIRED_ONLY

Для того же TCP/UDP gate выполнена сборка с `build_opt.h` и флагом
`FLPROG_NETWORK_BUILD_PROFILE=2` (`WIRED_ONLY`).

| Метрика | Universal | RMII/Wired-only | Экономия |
| --- | ---: | ---: | ---: |
| Flash | 1 096 784 B (83%) | 595 060 B (45%) | 501 724 B |
| Global RAM | 60 016 B (18%) | 36 084 B (11%) | 23 932 B |

Это ожидаемый результат: `WIRED_ONLY` исключает Wi‑Fi и OTA код на этапе
компиляции. Предупреждение `BluetoothSerial is deprecated` исходит из
`Flprog_Utilites` и на итоговый PASS/работу RMII не влияет.

## Следующая оптимизация, подготовлена к измерению

В `build_opt.h` включён флаг `FLPROG_UTILITES_DISABLE_BLUETOOTH=1`.
Он применим к данному gate: Bluetooth UART (порт 200) в нём не используется.
Реализация оставляет прежнее поведение по умолчанию для остальных FLProg
проектов, где Bluetooth требуется.

Повторная сборка подтвердила экономию:

| Метрика | До отключения Bluetooth | После | Экономия |
| --- | ---: | ---: | ---: |
| Flash | 595 060 B (45%) | 591 044 B (45%) | 4 016 B |
| Global RAM | 36 084 B (11%) | 35 908 B (10%) | 176 B |

Предупреждения `BluetoothSerial` исчезли. RMII/TCP/UDP-код не изменялся;
следующая проверка — комбинированный профиль RMII + Wi-Fi STA.
