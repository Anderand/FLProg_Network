# KC868-A16: RMII + Wi-Fi TCP/UDP gate

Отдельный аппаратный тест для KinCony KC868-A16. Проверяет TCP и UDP на LAN8720/RMII и Wi-Fi STA одновременно.

## Порты

| Транспорт | RMII IP | Wi-Fi IP |
|---|---:|---:|
| HTTP диагностика | `80` | `80` |
| TCP echo | `5001` | `5001` |
| UDP echo | `5002` | `5002` |

Один и тот же номер порта на двух IP — намеренно: это route-fixed серверы, а не маршрутизация через активный интерфейс.

## Проверка

1. Прошейте скетч и дождитесь IP-адресов из Serial (`115200`).
2. Откройте `/api/status` с каждого IP: должны быть `httpShared:1`, `error:0`.
3. TCP: отправьте строку на `<RMII_IP>:5001`, затем на `<WIFI_IP>:5001`; в обоих случаях придёт echo.
4. UDP: отправьте датаграмму на соответствующий IP и порт `5002`; ответ вернётся в тот же сокет.
5. Повторите TCP/UDP по Wi-Fi после отключения Ethernet. У счётчиков `wifi.traffic` должны расти RX/TX, у RMII link станет `false`.

`build_opt.h` служит параметрами Arduino IDE, не подключается через `#include`.
