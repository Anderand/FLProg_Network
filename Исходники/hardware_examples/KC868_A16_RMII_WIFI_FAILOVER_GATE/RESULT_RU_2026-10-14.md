# Результат: KC868-A16 RMII + Wi-Fi STA gate

Статус: **PASS — одновременная работа RMII и Wi-Fi STA подтверждена**.

## Подтверждённые результаты

- RMII/LAN8720: DHCP `192.168.100.12`, link up, HTTP `/` и `/api/status` отвечают `200`;
- Wi-Fi STA: DHCP `192.168.100.15`, HTTP `/api/status` отвечает `200`;
- JSON состояния с обоих адресов подтверждает `rmii.ready=true`, `wifi.ready=true`, `bothReady=true`, `error=0`;
- HTTP-сервер: `listening=true`, `sharedListeners=1` — один HTTP-парсер обслуживает два route-fixed listener;
- сборка: flash `1087620 / 1310720` байт (82%), глобальная RAM `58608 / 327680` байт (17%).

## Исправление, вошедшее в gate

`FLProgNetworkHttpServer::addSharedListener()` требует первичный HTTP listener с одним клиентским слотом. Gate запускает RMII с `maxClients=1`, а Wi-Fi listener подключает после фактического старта RMII listener в `loop()`. Это позволило использовать одну HTTP-контекстную память для обоих физических интерфейсов.
