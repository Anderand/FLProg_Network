# Проверки реализации

| Плата проверки | Загрузчик, Flash/RAM | Проверка блока, Flash/RAM |
|---|---|---|
| FLE4-24-1, F407 512 КиБ | 16048 / 1036 байт | 58924 / 7348 байт |
| FLE-10Mx, F103 256 КиБ | 15168 / 1008 байт | 56512 / 6440 байт |
| Generic F103VE, 512 КиБ | 15168 / 1008 байт | 56516 / 6440 байт |
| FLE4C-30MT, F407 1 МиБ | ранее проверенный загрузчик сохранён | 58924 / 7348 байт |

Это показатели arduino-builder, а не размер BIN с выравниванием.
Проверочный скетч блока не настраивает сеть и не предназначен для прошивки.

Выполнено:

- Компиляция трёх новых загрузчиков и четырёх вариантов OTA-блока.
- Проверка наличия реализации begin/eraseStage/commitStage в ELF для F103.
- Проверка адресов векторов, размера BIN, границ SRAM и SHA256.
- Проверка машинного кода: между записью MSP и BX нет обращения к стеку.
- Проверка непересечения областей и вместимости образа вместе с заголовком.
- Проверка создания и импорта трёх пакетов в коде менеджера с временными
  файлами и ранее скомпилированными образами; запуск компилятора в этом
  интеграционном тесте заменён готовыми результатами. Пакеты теста удалены.

Не выполнено: прошивка и испытания на физических F407 512 КиБ/F103,
отключение питания во время копирования, проверка импорта .ubi в GUI FLProg,
проверка всех 20 вариантов пинов/тактирования. XML блока проверен генератором.
Текущий работающий контроллер пользователя не перепрошивался.
