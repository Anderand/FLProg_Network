# Проект Web UI вне Arduino IDE

В редакторе задайте полный путь в поле **«Папка проекта»**, например
`E:\FLProg_Projects\a123`. Поле относится к текущему проекту и сохраняется в `.flpui`.
Если поле пустое, используются прежние папки `projects` и `project_packages` рядом с редактором.

Кнопка **«Сохранить»** записывает `a123.flpui`. Кнопка сборки дополнительно создаёт:

```text
E:\FLProg_Projects\a123\
  a123.flpui
  libraries\
    FLProg_WebUI\
    FLProg_WebUI_Project_a123\
      library.properties
      FLProg_WebUI_Start.ubi
      START_RU.md
      src\
        a123_webui.h
        a123_descriptor.h
```

WebUI сохраняется рядом с проектом в версии, соответствующей генератору.
Библиотеки в IDE при этом не меняются. Для обычной сборки непосредственно из FLProg
можно явно включить **«Копировать библиотеку проекта в Arduino IDE»**. Галочка
выключена по умолчанию; она копирует только сгенерированный пакет проекта.

## Блок и скетч

Импортируйте `FLProg_WebUI_Start.ubi` один раз. В универсальном профессиональном
блоке **Web UI Start** укажите **ID проекта**: `a123`, без пути и кавычек.
FLProg создаст `#include <a123_webui.h>` и вызов `FLPROG_WEBUI_BEGIN_SELECTED();`
после настройки Ethernet. SPI, MAC и DHCP задаются в проекте FLProg.
Транспорт в редакторе должен соответствовать интерфейсу FLProg, например W5500 №1.
Этот блок не добавляет OTA.

## Сборка менеджером

На вкладке **«Плата и сборка»** выберите свой `.ino`. В поле
**«Библиотеки проекта (папка libraries)»** выберите
`E:\FLProg_Projects\a123\libraries`.
Менеджер передаёт этот путь `arduino-builder` отдельным аргументом `-libraries`.
Пробелы в пути поддерживаются. Копировать проект в IDE не требуется.
Штатные библиотеки платформы по-прежнему берутся из выбранной IDE.

Поле сохраняется в настройках менеджера. При сборке загрузчика оно не используется.
Сам каталог сборки менеджера относится к OTA-профилям: отсутствие OTA-блока
в скетче не превращает такую сборку в обычную сборку с адреса `0x08000000`.
Выбор режима загрузки не меняйте без проверки профиля и смещения приложения.

Старый EXE r13 эту возможность не содержит; нужен новый комплект редактора и менеджер 0.7.8.
