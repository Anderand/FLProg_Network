# Состояния полей и синхронизация — FLE4D-30MT

25.10.2026. Прошивка **1.0.7-WEBUI1.7**, установленная по OTA на 192.168.100.8.

## Поведение

У каждого поля отдельный статус: «Синхронизировано», «Есть изменения»,
«Отправляется…», «Принято контроллером» или «Ошибка: …».
Рядом показано последнее прочитанное значение ПЛК. Если задана связь value,
используется её канал; иначе основной канал виджета. Поле ввода относится к
каналу setpoint, если такая связь задана. Это значения модели ПЛК, а не измерение
физического механизма. Пароли не выводятся: значение скрыто.

Опрос не затирает черновик даже после потери фокуса. Ошибка сохраняет введённое
значение; Enter/«Применить» отправляют, Escape отменяет черновик и берёт последнее
значение ПЛК. Квитанция приёма не означает физического выполнения.

В ответ состояния добавлено время работы ПЛК. При уменьшении времени или ревизии
страница запрашивает полный снимок без since. После ошибки связи следующий запрос
также полный, независимо от величины новой ревизии. Чистые поля обновляются,
черновики сохраняются и автоматически не отправляются.
Для числовых/bool команд модель отмечает новую ревизию, чтобы принятые значения
были видны также другим клиентам при опросе изменений.

Если новая прошивка меняет сам состав страниц/виджетов, страницу нужно обновить;
эта синхронизация относится к значениям текущего макета.

## Аппаратная проверка

1. Начальное значение: уставка 25, статус «Синхронизировано», факт ПЛК 25.
2. Ввод 30.3: «Есть изменения», при Enter — «Ошибка» (шаг поля 0.5).
3. Ввод 30.5 и Enter: «Отправляется…», затем «Принято контроллером»;
   значение ПЛК и применённая уставка стали 30.5.
4. В текстовом поле оставлен несохранённый «Черновик»; факт ПЛК — FLE4D test.
5. Выполнена повторная OTA-загрузка того же BIN. Страница браузера НЕ обновлялась.
   Автоперезапуск прошёл без ST-Link.
6. После восстановления связи уставка стала 25, статус «Синхронизировано»;
   «Черновик» остался, статус «Есть изменения», факт ПЛК остался FLE4D test.
   Появилось сообщение о полной синхронизации. Повторной отправки не произошло.

Подтверждения: before-restart.png, after-restart.png, after_restart_state.json.
Проверен неверный ввод на реальном ПЛК; ошибки HTTP/тайм-аутов — программными тестами.
Тесты исполняют фактический встроенный JS: принятие/ошибка, черновик, Escape,
сброс ревизии/времени, полный запрос после отключения. Старые тесты busy также проходят.

14 HTTP-маршрутов; максимальный статический ответ 1965 байт вместе с заголовками
при лимите 2048. Flash 137040, RAM 16112 байт. Прирост к 1.0.6: Flash +1720, RAM +0.
BIN 137524 байта, приложение с 0x08010000, SHA-256 проверен.

Физические выходы не переключались. Git, GitHub и архив r5 не менялись.
Исходники находятся в рабочем flprog_webui_next и рядом с этой тестовой прошивкой.
