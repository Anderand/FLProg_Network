# Оформление существующих групп

25.10.2026. FLE4D-30MT / STM32F407VG / W5500, core3.0.0.
По OTA установлена **1.0.15-GROUPS**, IP **192.168.100.12**.
Git, EXE и опубликованный общий r13 не изменялись.

## Решение по нашей концепции

Сначала сравнили идею контейнеров с существующим редактором. Основной режим —
наша сетка на 12 колонок и именованные группы. Для текущей задачи достаточно
настроек уже имеющейся группы. Вложенные контейнеры и строка/столбец не добавлялись;
вернуться к ним стоит при конкретной потребности проекта.

## Настройка

Откройте свойства любого элемента группы → «Основное» → «Вид группы»:

- «Показывать рамку группы».
- «Внутренний отступ, px»: целое 0–32.
- «Между элементами, px»: целое 0–32.

Настройки общие для всех элементов с этим именем группы на текущей странице.
Одинаковое имя на другой странице имеет независимое оформление. Без группы
эти настройки недоступны. Новая группа получает стандартное оформление;
перевод элемента в существующую группу применяет её настройки.
Оформление не меняет X/Y/W/H, каналы, связи и программу FBD.

Стандарт для старых проектов: рамка включена, внутренний отступ12px,
расстояние10px. Старые C++-инициализаторы тоже сохраняют этот вид.
Рамка самой карточки виджета остаётся отдельной от рамки общей группы.

Настройки хранятся в странице один раз:

```json
"groupStyles": {
  "Управление": {"border": false, "padding": 16, "gap": 6}
}
```

Сборщик переносит нужное оформление в descriptor каждого члена группы.
Внутреннее поле C++ groupStyle добавлено последним для совместимости.
Проект проверяет типы и диапазоны до сборки; HTTP-буферы не увеличиваются.
Названия групп отображаются как текст. Оформление не исполняет произвольный CSS.

## Что проверено

- 45 автоматических тестов и verify_release.py прошли.
- Старые настройки по умолчанию; неверные типы/диапазоны; разные страницы;
  генерация descriptor без изменения исходного проекта и каналов.
- Runtime обновляет оформление, сохраняя узлы поля и черновик;
  локальная сетка12 колонок и координаты не меняются.
- GUI: на группе из двух элементов установлены padding16/gap6/без рамки.
  В соседней группе остались padding4/gap6. Эти параметры совпали
  с computed styles офлайн-предпросмотра.
- На ПЛК: все10 описаний виджетов передают ожидаемое оформление.
  Все прежние поля descriptor, координаты и связи побайтно сохранены;
  FLProg_Network совпадает с проверенной 1.0.14, включая отказ для %00.
- 25 gzip-ресурсов прочитаны с FLE4D и совпали с исходниками; 14 маршрутов.
  В C++ по-прежнему проходят144 проверки шаблонов.
- Веб: черновик GH-012 сохранился после опроса при значении ПЛК AB-123;
  явное применение дало GH-012 и подтверждение данными. Команды не запускались,
  физические выходы не менялись. В проверенной вкладке ошибок JS нет.
- Мобильный вид390px: карточки на полной ширине, scrollWidth375<=390,
  горизонтального переполнения нет. Временный размер браузера сброшен.

Пример: projects/group_appearance.flpui.
