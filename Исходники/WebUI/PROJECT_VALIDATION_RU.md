# Проверка проекта перед сборкой

## Как пользоваться

1. Откройте проект и нажмите **«Проверить проект»**.
2. В списке указаны страница, виджет и причина каждой проблемы.
3. Нажмите **«Открыть виджет»**: откроется нужная страница и настройки
   «Данные» для каналов или «Сетка» для размещения.
4. Исправьте настройки и нажмите **«Проверить повторно»**.
5. Нажмите **«Собрать и установить»**. Проверка повторится автоматически.

## Ошибки — сборка остановлена

- Отсутствующий основной канал или канал дополнительной связи.
- Несовместимый тип: например, float у переключателя вместо bool,
  текст у числового поля, нечисловая серия графика.
- Неверное направление канала или связи: команда направлена в канал,
  доступный только для чтения; показание берётся из командного канала.
- Неверные или повторные ID, номера FBD, роли дополнительных связей.
- Некорректная сетка и существующие ограничения генератора проекта.

Для busy/alarm требуется bool; тип setpoint должен совпадать с основным
каналом. Статическим текстам, заголовкам, разделителям и ссылкам канал
не нужен. Связи setpoint предназначены для элементов управления.

## Предупреждения — пересечения

Пересечение проверяется между элементами одной страницы и одной группы.
Элементы разных групп и элементы, только соприкасающиеся границами,
не считаются пересекающимися.

У предупреждения есть переход к обоим элементам: **«Открыть виджет»** и
**«Другой виджет»**. Если наложение намеренное, нажмите
**«Собрать с предупреждениями»**. При наличии ошибок эта кнопка недоступна.

После изменения проекта список помечается устаревшим. Переход по старой
проблеме сначала обновляет список; выберите проблему повторно.
Подтверждение предупреждений относится только к проверенной версии проекта.

## Границы проверки

Это проверка модели проекта на компьютере. Она не проверяет физическую
проводку, сеть, программу FBD или фактическую доступность контроллера.
Проверка сама не записывает проект, не устанавливает библиотеки и не прошивает
контроллер. Сервер повторяет проверку при сборке, даже при прямом запросе API.
