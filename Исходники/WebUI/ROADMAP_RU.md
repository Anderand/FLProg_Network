# Дорожная карта FLProg Web UI 1.0

## Правила архитектуры

- `FLProg_Network` содержит только разработческий сетевой API.
- `FLProg_WebUI` содержит общий runtime и адаптеры.
- `.flpui` хранит только дизайн и контракт конкретного проекта.
- project package содержит descriptor и конфигуратор конкретного проекта.
- Изменение layout/темы не меняет FBD-схему; изменение канала является изменением контракта.

## Очередь выполнения

1. **API-интеграция FLProg_Network** — каталог публичных API и генерация
   Wi-Fi/W5500 HTTP выполнены. W5500 использует проверенные в generated sketch
   макросы `FLPROG_WIZNET_INTERFACE1` и `FLPROG_WIZNET_INTERFACE2`.
2. **Модель дизайна** — выполнена: `theme`, `layout`, `x/y/w/h`, цвета,
   иконки, min/max/step.
3. **Редактор** — выполнен: 12-колоночная сетка, свойства, color picker,
   drag, точное изменение размеров, text input, мобильный предпросмотр,
   выделение пересечений, дублирование и отмена изменений.
4. **Runtime Web UI** — выполнен: descriptor-метаданные, CSS-grid, цвета
   виджетов, indicator/switch/slider/text-input и безопасная очередь команд.
   Страница разделена на компактные HTTP-ресурсы.
5. **FLProg blocks** — выполнен единый `.ubl` для Publish/Command Bool,
   Int32, Float и Text; XML проверен статически.
6. **Сборка и установка** — выполнены generator package, автоматическая
   установка в sketchbook и корректные Arduino metadata.
7. **Регрессия** — статическая и очная ESP8266 Wi-Fi проверка выполнены.
   Очные ESP32/W5500 отложены по решению пользователя; package и adapter для
   W5500 подготовлены и статически проверены.
8. **Передача** — выполнены RU/EN README, demo-проект и чистый архив передачи.

## Критерий завершения

Пользователь создаёт проект в редакторе, выбирает публичный транспорт
FLProg_Network, раскладывает виджеты на сетке, экспортирует package/UBL,
связывает универсальные блоки в FLProg и получает адаптивный интерфейс после
прошивки без ручного C++-кода.
