# Исправления по инспекции, 15.10.2026

Исправлено:

- Самодостаточная исходная поставка редактора: tools, integration, projects внутри папки программы.
- BAT проверяет запуск Python 3.7+, а не только наличие py.exe. Используется запасной Python FLProg.
- Совместимость копирования с Python 3.7; существующие пользовательские проекты при упаковке не перезаписываются.
- Проверка ID до записи проекта, создание папки projects при сохранении.
- Настройка папки библиотек через переменную окружения FLPROG_LIBRARIES.
- Номера FBD сохраняются при перестановке/удалении каналов; новые получают свободные номера. Неверные и повторные номера отклоняются, а не меняются незаметно.
- Перетаскивание учитывает фактическую сетку и отступы. В телефонном режиме перемещение отключено: точные координаты доступны в настройках.
- Опрос больше не очищает всю страницу: активное поле, неизменившиеся карточки и сканер сохраняются. Изменившиеся неактивные карточки заменяются отдельно.
- Ошибка загрузки виджета не помечает страницу успешно загруженной.
- Связи bindings теперь попадают в descriptor, JSON API и state polling. setpoint перенаправляет запись с виджета; alarm/busy/result показываются в карточке; series1/series2 рисуются дополнительными линиями графика.

Проверено: пять Python-регрессий (адреса, дубли, bindings и сборка); синтаксис app.js и пяти runtime-скриптов; запуск отдельной поставки на Python 3.7.2 FLProg; HTTP 200 главной страницы, демо и каталога API. Arduino IDE собрала ESP8266 binding smoke sketch: 275696 байт Flash (26%), 35172 байта глобальной RAM (43%); получены ELF и BIN. Это проверка компиляции, не доказательство работы на реальном контроллере.

Нужен аппаратный проход на ESP8266 после компиляции пакета: проверка всех типов дополнительных связей, особенно новых линий графика, на реальном браузере и контроллере.

## Подключение к FLProg

Установите FLProg_Network и FLProg_WebUI в sketchbook/libraries. Редактор храните отдельно. После «Собрать и установить» проверьте сообщение с путём установки; если libraries не найдена, скопируйте созданную FLProg_WebUI_Project_<ID> самостоятельно. Импортируйте созданный FLProg_WebUI_Configure_<ID>.ubi и разместите один конфигуратор в проекте с выбранным сетевым интерфейсом. Канальные блоки используйте из комплекта .ubl, с номерами редактора. Изменение оформления не требует повторного импорта конфигуратора при прежних ID и транспорте, но требует пересборки и прошивки.
