# Штатные универсальные блоки — контракт 0.1

Блоки не генерируются заново при изменении страницы Web UI. Они работают с
активной моделью, которую подключает один профессиональный Web UI Start
с параметром «ID проекта».

Готовый комплект: `Publish Bool/Int/Float/Text` и
`Command Bool/Int/Float/Text`.
У всех рабочих блоков числовой `CHANNEL` — стабильный номер из descriptor проекта,
а не строковое HTTP-имя. Визуальные изменения не меняют FBD-схему.

У блоков Publish: `EN`, `CHANNEL`, `VALUE`. У Command: `EN`, `CHANNEL`,
выходы `NEW`, `VALUE`. `NEW` становится истинным ровно в цикле, когда из
браузера пришла новая команда. Импортируйте нужные `.ubi` из этой папки.

Пользовательские номера: 101–255. Системные №0–100 обслуживаются автоматически.
Нужные номера, типы и блоки смотрите по кнопке «Каналы FLProg» в редакторе
или в CHANNELS_RU.md рядом с собранной библиотекой проекта.
