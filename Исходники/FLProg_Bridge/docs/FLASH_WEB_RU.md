# Веб из Flash по UART — проверка 28.10.2026

FLE4D-30MT, STM32F407VG, COM5/UART6 PC6/PC7, 115200. Прошивка 1.0.9-BRIDGE-FLASH, мост 0.3.0. Основа: пользовательский проект4, DHCP.

При физически отключённом Ethernet весь веб скачан из Flash ПЛК в пустой кеш по UART: 15438 байт gzip (72634 после распаковки), 2,234 с, 70 обменов. Повторная проверка кеша: 0,032 с, один обмен. SHA-256 совпал, ошибок кадров 0. TCP контроллера был недоступен. Папка сайта на PC не нужна.

Проверены четыре страницы, программная команда с отдельной обратной связью, OTA и сохранность первых64 КиБ загрузчика. Физические выходы в этой проверке не переключались.

Flash: 350724 → 366572 байта (+15848). Статическая RAM: 51628 → 51644 байта (+16). Порция ресурсов до224 байт; весь пакет в RAM ПЛК не копируется.

## Запуск

Запустите Мост_связи\FLProg_Bridge.exe, выберите COM5/115200, подключитесь. Поле «Резервный веб» оставьте пустым. Откройте локальный адрес из окна. Кеш проверяется по SHA-256, при смене пакета загружается новый веб. Команды после обрыва автоматически не повторяются.

## Известная проблема диагностики Ethernet

После отключения кабеля network_ready продолжает показывать true: ветка DHCP bound восстанавливает готовность между проверками физического линка. Сохранённый IP не доказывает наличие кабеля. Дефект не исправлен в данной сборке; офлайн-проверка основана на физическом отключении и недоступности TCP.
