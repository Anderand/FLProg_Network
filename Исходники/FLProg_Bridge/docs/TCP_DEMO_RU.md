# FLProg Bridge 0.4.1-preview.1 — демо TCP/ESP без аппаратуры

Запустите FLProg_Bridge.exe из этой папки. Python не нужен; _internal должен
оставаться рядом. Никакая ESP/ПЛК автоматически не выбирается и не прошивается.

1. Нажмите «Демо TCP/ESP». Программа запустит виртуальный мост на127.0.0.1
   и подключится к нему по настоящему TCP. Значение в поле адреса будет локальным.
2. Нажмите «Открыть веб-интерфейс». Это демонстрационная сервисная страница каналов,
   а не проект FLE4D:10=описание,101=уставка(float25),102=переключатель(false).
3. Прочитайте канал101. Для изменения включите «Разрешить команды» в программе,
   заново прочитайте канал, затем передайте значение и проверьте повторным чтением.
   Меняются только виртуальные значения в памяти компьютера.
4. «Обрыв демо» прерывает локальное TCP-соединение. При включённом восстановлении
   появится новый сеанс. Демонстрационная модель сбрасывается к начальным значениям;
   старые команды не повторяются. Это сценарий, а не утверждение о поведении реального ПЛК.
5. «ПЛК молчит (демо)» оставляет TCP доступным, но подавляет ответы виртуального UART.
   Через таймаут будет показано: TCP установлен, ответа ПЛК нет. Снимите галочку
   и дождитесь восстановления. Недоставленные команды не ставятся в очередь.

Обычный «Подключить» по-прежнему работает с явно введённым COM или tcp://IP:порт.
В демо используются только localhost и память PC: Wi-Fi, UART, ESP, реальная
прошивка и физические выходы не испытываются. Modbus/MQTT через мост ещё не реализованы.

Для автоматизации: --headless --demo-tcp --no-browser --status-file <файл.json>.
--demo-tcp нельзя сочетать с COM, внешнимTCP, --demo или локальной папкой сайта.
Запись по умолчанию закрыта; --allow-writes разрешает её явно.

Проверено:4новых теста TCP-демо,20тестов протокола с пересобранным C++peer,
3прежних TCP-теста (включая веб изFlash на нативном стенде), запуск EXE с чтением,
запретом записи по умолчанию и явно разрешённой виртуальной записью.
Программная проверка не заменяет физический тест ESP↔UART↔FLE4D.
GitHub и общий r17 этим прототипом не обновлялись.
