# FLProg Network — r14

**[Скачать полный архив с EXE редактора и OTA-менеджера](https://github.com/Anderand/FLProg_Network/releases/download/v2026.10.27-r14/FLProg_Network_2026-10-27_r14.zip)** · [Страница релиза](https://github.com/Anderand/FLProg_Network/releases/tag/v2026.10.27-r14)

Общий комплект от27.10.2026: три библиотеки, блоки FLProg, переносимый Web UI
редактор и OTA-менеджер **0.7.9**. Оба инструмента входят в FLProg Network.
Кнопка Code → Download ZIP и автоматические Source code содержат исходники;
готовые EXE находятся в указанном архиве из Assets.

## Установка и запуск

1. Распакуйте архив целиком в доступную для записи папку.
2. Закройте FLProg и IDE. **Вручную** скопируйте только три папки из
   `Библиотека` — **FLProg_Network, FLProg_WebUI, Flprog_Modbus** — в
   `<IDE>\portable\sketchbook\libraries`, заменив файлы этих библиотек.
   Штатные RT_HW_00_BASE, Flprog_Utilites, Wire и другие библиотеки не меняйте.
   Установщиков библиотек и соответствующих BAT в комплекте нет.
3. Для STM32 требуется **core 3.0.0**. Версия2.7.1 не поддерживается;
   версия Arduino IDE1.8.19 сама по себе не определяет ядро платы.
4. Импортируйте нужные `.ubi/.ubl` из `Блоки_FLProg`. Для Web UI используйте
   один **FLProg_WebUI_Start.ubi** и задайте **ID проекта**. SPI/Ethernet/DHCP
   настраиваются в проекте FLProg. Копирование библиотек само блоки не импортирует.
5. Редактор: **Редактор/FLProg_WebUI_Editor.exe** или **START_WEB_EDITOR.bat**.
   Откроется http://127.0.0.1:8766/. Python не нужен. Переносите всю папку
   `Редактор`, включая `_internal`. При занятом порте запустите EXE с другим
   портом первым аргументом, например `FLProg_WebUI_Editor.exe 18843`.
6. Менеджер: **OTA_Менеджер/FLProg_STM32_OTA_Manager.exe** или
   **START_OTA_MANAGER.bat**. Оставляйте профили и build_tools рядом с EXE.

## Совместимость перед сборкой

В редакторе задайте папку проекта вне IDE и нажмите **«Совместимость»**,
затем **«Собрать пакет»**. В `<папка проекта>/libraries` появятся библиотека
проекта и согласованная FLProg_WebUI. Копирование проекта в IDE выключено
по умолчанию. Исходная схема FLProg и её настройки сети не меняются.

**Существующие пакеты WebUI один раз пересоберите из `.flpui` новым EXE.**
ID проекта, номера CHANNEL и FBD-связи менять не нужно. Новый пакет содержит
паспорт `WEBUI_COMPATIBILITY.json`; старый пакет без него не проходит новую
проверку менеджера. Сохраняйте исходный `.flpui` отдельно от сгенерированных файлов.

В менеджере на вкладке **«Плата и сборка»** выберите IDE, свой `.ino` и
именно папку **libraries** проекта. **«Проверить совместимость»** проверяет
заголовок ID_webui.h, паспорт, runtime, Network и core 3.0.0. При ошибке
компилятор не запускается. Дубли библиотек показываются предупреждениями.
Проверка сама ничего не прошивает и не устанавливает в IDE.

[Подробная инструкция и границы проверки](Документация/BUILD_COMPATIBILITY_RU.md).
Проверка экспорта не подтверждает чужую IDE; менеджер разбирает прямые
include выбранного скетча, а не весь препроцессор. При дублях смотрите пути
реально выбранных библиотек в логе компиляции.

## Что ещё вошло после r13

- Один профессиональный Start с ID проекта и проекты вне IDE.
- Таблица каналов для FBD, экспорт Markdown/JSON.
- Снимки и повторяемые сценарии предпросмотра: уставка, busy/result,
  потеря связи и перезапуск. Это локальная модель, FBD не исполняется.
- Опрос500–60000мс, полный снимок после возврата, разрешения enabled,
  шаблоны полей, оформление существующих групп и системная диагностика.
- Сохранены gzip, Flash-stream, уведомления, безопасные повторы GET,
  хеш-кеш и защита от повторной отправки команд.

Проверены **83 теста**, оба EXE и компиляция FLE4D с внешними библиотеками:
Flash158832, staticRAM19392, без роста относительно той же прошивки1.0.21.
При упаковке устройство не перепрошивалось. Нативную проверку скрытия
вкладки пользователь отложил: IAB её не сообщает; обработчик события
проверен отдельно с настоящим ПЛК. Windows7 и остальные платы отдельно
не объявляются испытанными. [Отчёт r14](Проверки/RELEASE_R14.md).

BIN1.0.10-LOAD в примерах сохранён как исторический проверенный образ, а не
как прошивка новых возможностей r14. Установка EXE сама не обновляет веб ПЛК:
для новых возможностей runtime пересоберите и загрузите своё приложение.
OTA-приложение для существующего FLE4D использует0x08010000; не записывайте
его по адресу загрузчика0x08000000. Проверенный профиль менеджера сохранён,
его старый BIN не подменяется автоматически. Выбирайте свой BIN явно.

SHA-256 ZIP находится рядом с архивом, SHA всех файлов — MANIFEST_SHA256.json.
Не смешивайте библиотеки и заголовки разных комплектов. Сохранены авторские
уведомления компонентов; новой общей лицензии этот выпуск не назначает.
