# FLProg Network

Сетевые библиотеки и инструменты для FLProg: Web UI редактор, STM32 OTA-менеджер, блоки и примеры.

**[Подробные инструкции и справочник](Документация/README.md)**: [установка](Документация/УСТАНОВКА.md), [редактор](Документация/РЕДАКТОР.md), [OTA-менеджер](Документация/OTA_МЕНЕДЖЕР.md), [блоки](Документация/БЛОКИ.md), [ошибки](Документация/УСТРАНЕНИЕ_ОШИБОК.md), [разработчику](Документация/РАЗРАБОТЧИКУ.md).

Инструкции и справки поставляются в Markdown (`.md`) и доступны в этом же виде внутри готового архива.

## 1. Скачать готовый комплект

1. Откройте **[последний релиз](https://github.com/Anderand/FLProg_Network/releases/latest)**.
2. В разделе **Assets** скачайте **`FLProg_Network_2026-10-24_r2.zip`**. Это полный комплект с EXE, библиотеками, блоками и загрузчиками.
3. Распакуйте архив целиком, например в `C:\FLProg_Network`. Запускайте программы из распакованной папки.

**[Скачать готовый ZIP от 24.10.2026 напрямую](https://github.com/Anderand/FLProg_Network/releases/download/v2026.10.24/FLProg_Network_2026-10-24_r2.zip)**

Файлы **Source code (zip/tar.gz)** и кнопка **Code → Download ZIP** содержат исходники, без готовых EXE. Для обычной установки нужен архив, указанный выше.

Внутри общего комплекта:

| Папка | Назначение |
|---|---|
| `Библиотека` | Три библиотеки для IDE FLProg |
| `Блоки_FLProg` | Блоки OTA, диагностики W5500, MQTT и WebUI |
| `Редактор` | Готовый Web UI редактор с EXE |
| `OTA_Менеджер` | Готовый менеджер с EXE, профилями и загрузчиками |
| `Примеры` | Тестовый проект FLE4D 1.0.1 |
| `Исходники`, `Проверки` | Исходники и отчёты |

## 2. Установить три библиотеки

Устанавливаются только:

- **FLProg_Network** — сетевая библиотека;
- **FLProg_WebUI** — библиотека интерфейса контроллера;
- **Flprog_Modbus** — исправленная библиотека Modbus.

1. Закройте FLProg и Arduino IDE.
2. Откройте папку `Библиотека` в распакованном комплекте.
3. Скопируйте **три папки целиком** — `FLProg_Network`, `FLProg_WebUI`, `Flprog_Modbus` — в `<папка IDE>\portable\sketchbook\libraries`. При обновлении подтвердите замену файлов этих трёх библиотек.
4. Заново откройте FLProg.

Правильная структура:

```text
portable/sketchbook/libraries/
├── FLProg_Network/library.properties
├── FLProg_WebUI/library.properties
└── Flprog_Modbus/library.properties
```

Не создавайте дополнительный уровень `FLProg_Network/FLProg_Network`. Если FLProg использует виртуальный диск `Z:`, копируйте в реальную папку IDE и перезапускайте FLProg для обновления виртуальной копии.

## 3. Добавить блоки в FLProg

Копирование библиотек не импортирует пользовательские блоки автоматически.

1. Откройте в FLProg работу с пользовательскими блоками/библиотеками и выберите импорт. Название пункта зависит от версии FLProg.
2. Выберите нужный `.ubi` из папки `Блоки_FLProg`. Файл `.ubl` — комплект блоков для импорта пользовательской библиотеки.
3. После импорта найдите блок в пользовательской библиотеке и добавьте его в проект.

| Папка | Что импортировать |
|---|---|
| `OTA` | `FLProg_OTA_Universal.ubi` — обновление STM32 по сети |
| `W5500_Diagnostic` | `FLProg_W5500_Diagnostic.ubi` — диагностика Ethernet |
| `MQTT` | `FLProg_Network_MQTT_Core.ubi`, `…_Publish.ubi`, `…_Subscribe.ubi` |
| `WebUI` | `FLProg_WebUI_Universal_Blocks.ubl` либо нужные `Publish_*` и `Command_*` в формате `.ubi` |

При обновлении старого OTA-блока замените его на версию из комплекта. Используйте один OTA-блок на проект. Настройки SPI и Ethernet задавайте штатными средствами **проекта FLProg**.

Импорт через интерфейс FLProg отдельно не испытывался; XML блоков и контракт OTA проверены. Подробности подключения находятся в README соответствующей папки блока.

## 4. Запустить Web UI редактор

1. Запустите **`START_WEB_EDITOR.bat`** из корня комплекта либо **`Редактор\FLProg_WebUI_Editor.exe`**.
2. Редактор откроется в браузере по адресу **http://127.0.0.1:8766/**. Это редактор на компьютере, а не веб-страница контроллера.
3. Нажмите **«Демо»** для знакомства или **«Новый»** для своего проекта. Задайте ID проекта, страницы, каналы и транспорт.
4. Нажмите **«Собрать и установить»**. При пустом поле «Папка пакетов» результат находится в `Редактор\project_packages`. Сохранённые проекты — в `Редактор\projects`.
5. Прочитайте итог внизу окна. Автоустановка рассчитана на `C:\F-981\FLProg\ideV8`. Для другой IDE задайте переменную окружения `FLPROG_LIBRARIES` с путём к её `portable\sketchbook\libraries` **до запуска редактора** либо скопируйте созданную папку `FLProg_WebUI_Project_<id>` туда вручную.
6. Импортируйте созданный **`FLProg_WebUI_Configure_<id>.ubi`** из пакета и добавьте конфигуратор в проект FLProg. Подключите нужные универсальные Publish/Command-блоки; номер `CHANNEL` должен соответствовать каналу редактора.

**Python для готового EXE не нужен.** Переносите всю папку `Редактор`: DLL, runtime и генератор нужны для работы. Если страница не открывается, проверьте, не запущена ли уже другая копия редактора на порту 8766.

## 5. Запустить OTA-менеджер

Запустите **`START_OTA_MANAGER.bat`** либо **`OTA_Менеджер\FLProg_STM32_OTA_Manager.exe`**. Переносите папку менеджера целиком: рядом с EXE должны оставаться `profiles` и `build_tools`. Настройки сохраняются рядом с EXE.

По умолчанию выбран **проверенный FLE4D-30MT 1.0.1**. Остальные профили доступны только после включения **«Показать непроверенные платы и профили»**. Старые тестовые профили удалены.


### Подготовить проект и первую прошивку

1. Настройте SPI/Ethernet в FLProg и добавьте OTA-блок.
2. Задайте `EN = true`, `NET_NUM` — номер сети проекта (обычно `1`), `VERSION` — строку версии, например `"1.0.0"`. `PASSWORD` может быть пустой строкой; при обновлении указывайте тот же пароль.
3. Экспортируйте скетч `.ino` из FLProg.
4. На вкладке **«Плата и сборка»** менеджера выберите **точную модель платы**, папку IDE и скетч. Нажмите **«Собрать BIN и пакет»**.
5. Для первой установки запишите совместимые загрузчик и приложение через **ST-Link/SWD**. Для этого нужен установленный **STM32CubeProgrammer**.

Профиль с пометкой «нужен BIN проекта» содержит только загрузчик. Сам загрузчик не запускает Ethernet: сеть и OTA должны присутствовать в приложении. Готовая тестовая прошивка FLE4D предназначена для указанной модели, а не для любой STM32.

### Обновлять по сети

Сканер также находит Arduino OTA на ESP (обычно порт 8266). Для этого используются multicast и прямые mDNS-запросы. Прошивка ESP через STM32-протокол этого менеджера не поддерживается.

1. Дождитесь запуска Ethernet и готовности OTA (`READY = true`). Компьютер должен иметь сетевой доступ к контроллеру.
2. На вкладке **«Поиск OTA»** укажите свою подсеть, например `192.168.100.0/24`, порт `3233` и нажмите **«Найти OTA»**.
3. Выберите найденный контроллер и нажмите **«Использовать выбранный IP»** либо введите IP вручную на вкладке «Прошивка».
4. Выберите подходящий профиль и через **«Выбрать BIN…»** укажите приложение, собранное для OTA и этой платы. Не выбирайте `bootloader.bin` в поле приложения.
5. Введите пароль контроллера и нажмите **«Обновить по OTA»**. Кнопка **«Проверить OTA-порт»** только проверяет связь и не отправляет прошивку.
6. Дождитесь окончания передачи и автоматического перезапуска приложения с поддержкой автоперезапуска. После получения IP повторите поиск и проверьте новую версию.

OTA записывает область приложения через staging, сохраняя загрузчик. Обычный BIN со смещением `0x08000000` не заменяет приложение, собранное для OTA. Модель в сканере берётся из выбранной платы сборки, версия — из входа `VERSION`.

## Если что-то не получается

| Симптом | Что проверить |
|---|---|
| `…h: No such file or directory` | Три библиотеки установлены в реальную папку нужной IDE, без лишнего уровня вложенности; FLProg перезапущен |
| Блок не появился | `.ubi`/`.ubl` импортирован в пользовательские блоки, а не только скопирован на диск |
| Редактор не открылся | Запуск из распакованной папки вместе с DLL; порт 8766 не занят другой копией |
| Пакет редактора не установлен | Посмотрите итог сборки; при необходимости скопируйте папку пакета в libraries своей IDE |
| OTA не находится | Контроллер получил IP, в приложении включён OTA, указан правильный порт и подсеть |
| После сброса порт временно недоступен | Дождитесь запуска приложения и получения DHCP-адреса; затем повторите поиск |

## Исходники

- `Библиотека/FLProg_Network` — основная сетевая библиотека.
- `Библиотека/FLProg_WebUI` — библиотека Web UI.
- `Библиотека/Flprog_Modbus` — исправленная рабочая библиотека Modbus.
- `Блоки_FLProg` — OTA, диагностика W5500, MQTT и WebUI.
- `Исходники/WebUI` — исходники редактора и генератора пакетов.
- `Исходники/hardware_gates` — менеджер, сборщик и загрузчики STM32.
- `Примеры` и `Проверки` — примеры и отчёты с ограничениями проверок.

## Версии и границы проверки

Снимок от 24.10.2026: менеджер 0.7.7, OTA-блок 0.4, пример FLE4D 1.0.1.
В готовом комплекте 20 загрузчиков и 21 профиль. Физическая проверка всех плат не выполнялась.
OTA для STM32 в этом снимке: F407 512/1024 KiB и F103 256/512 KiB с W5500.
Готовые BIN, EXE, профили и пакеты находятся в ZIP раздела Releases.

Существующие авторские уведомления компонентов сохранены. Новая общая лицензия этим импортом не назначается.
