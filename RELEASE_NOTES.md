# Совместимость RESET и SPI в исходниках от 12.11.2026

Добавлены `setPinRST` и `setSpeedSPI`: `pr1` собирается без правки скетча. RESET настраивается до первого `pool()`, 255 не вызывает GPIO, частота SPI меняется без переинициализации сети. Публичные заголовки и тесты обновлены.

28.10.2026. Настраиваемый опрос MQTT: 10 мс в простое, 1 мс при обмене,
одна порция до 64 байт; TCP-сокет и сервис используют одно расписание.
Принятые команды будят обработку. Динамические подписки сохранены.
Core/Publish/Subscribe v0.3 для Basic и Professional, документация и API обновлены.

Оба EXE и прошивки из r15 сохранены байт в байт. Старые выпуски не перезаписаны.
