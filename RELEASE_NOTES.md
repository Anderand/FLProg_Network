# r18 — Network dev20 и отдельный комплект редактора

14.11.2026. В опубликованные исходники включены финальные изменения EIS: RT_HW session API и отложенная фабрика backend, типизированный реестр устройств, дополнения RESET/SPI и отдельный include IPAddress для OTA. Метки версии заголовка и library.properties согласованы: dev20, API 10006.

Сохранены исправления актуального main (`e68f94f`): управляемый RESET для Arduino SPI, запрет поздней перенастройки, смена частоты без переинициализации сети и запуск старых проектов без дополнительной паузы, если RESET/задержка не настраивались. Автоматический RT_HW и явно выбранный Arduino backend используют каждый свой GPIO writer.

Обновлены исходники WebUI, генераторы, проекты и runtime. Переносимый EXE пересобран; редактор передаётся отдельно от Network. Публичные API-копии и манифест синхронизированы.

Проверки и границы подтверждённого результата: [отчёт r18](Проверки/RELEASE_R18/README.md). Физическое устройство при подготовке выпуска не использовалось.

# Совместимость RESET и SPI в исходниках от 12.11.2026

Добавлены `setPinRST` и `setSpeedSPI`: `pr1` собирается без правки скетча. RESET настраивается до первого `pool()`, 255 не вызывает GPIO, частота SPI меняется без переинициализации сети. Публичные заголовки и тесты обновлены.

[Контракт методов](Документация/NETWORK_SETTERS_RU.md) · [Результаты проверки](Проверки/NETWORK_SETTERS/RESULTS_RU.md). Это обновление Git; ранее выпущенные архивы и BIN не заменены.
