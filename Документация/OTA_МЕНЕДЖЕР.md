# STM32 OTA-менеджер

Текущая версия — **0.7.7**. Запуск: `OTA_Менеджер/FLProg_STM32_OTA_Manager.exe` или `START_OTA_MANAGER.bat`. Python для запуска EXE не нужен. Рядом должны оставаться `profiles` и `build_tools`. Настройки сохраняются в `settings.json` рядом с EXE; пароль OTA в этот файл не сохраняется.

## Профили и проверенность

При каждом запуске галочка **«Показать непроверенные платы и профили»** выключена. Доступен проверенный профиль **FLE4D-30MT / STM32F407VG / W5500, приложение 1.0.1**. Его статус привязан к известным SHA-256 загрузчика и приложения.

Галочка открывает остальные 20 профилей для испытаний и каталог сборки. Она не делает платы проверенными. Старые OTA v1, диагностические профили и приложение 1.0.0 удалены из актуального комплекта. При выключении галочки выбор возвращается на доступный профиль; неподходящий ранее выбранный BIN очищается.

Профиль описывает модель, память, адреса, протокол и хэши артефактов. Надпись «загрузчик собран» подтверждает наличие файла, а не аппаратное испытание.

## Отличие файлов

| Файл | Для чего нужен |
|---|---|
| `bootloader.bin` | Начальная запись загрузчика через SWD |
| `application.bin` или свой BIN | Программа, собранная для OTA-разметки выбранной платы |
| `.fwpkg` | Пакет профиля с загрузчиком и приложением |
| `profile.json` | Метаданные и контрольные суммы пакета |

Загрузчик сам не создаёт Ethernet и не получает IP. Сеть и OTA-сервис должны работать в приложении. Выбор профиля только с загрузчиком не заменяет сборку приложения пользователя.

## Подготовка проекта

1. Установите библиотеки и импортируйте OTA-блок.
2. Настройте SPI, W5500, DHCP или статический IP **в проекте FLProg**.
3. Укажите `EN=true`, правильный `NET_NUM`, пароль и строковую версию `VERSION`.
4. Экспортируйте `.ino` из FLProg.
5. На вкладке «Плата и сборка» выберите точную плату, IDE и скетч; используйте «Собрать BIN и пакет».

Каталог сборки содержит непроверенные конфигурации и открывается галочкой. Проверенный готовый профиль FLE4D находится на вкладке «Прошивка». Не подменяйте отсутствующий профиль похожей платой без проверки памяти и распиновки.

Для сборки нужны `arduino-builder.exe`, соответствующее ядро STM32 и штатные зависимости IDE. В текущем снимке используется ядро STMicroelectronics STM32 3.0.0.

## Первая установка

Нужны ST-Link/SWD и установленный STM32CubeProgrammer. Выберите совместимый профиль/пакет, укажите путь к `STM32_Programmer_CLI.exe` и выполните «Первичная установка по SWD».

Операция записывает загрузчик и приложение по адресам выбранного профиля. Убедитесь, что подключена именно тестируемая плата. Кнопка «Перезапуск по SWD» требует ST-Link и не является сетевым сбросом.

## Обновление по сети

1. Дождитесь IP и `READY=true` у OTA-блока.
2. На вкладке «Поиск OTA» задайте IPv4-подсеть и порт FLProg OTA, обычно `3233`.
3. Нажмите «Найти OTA» и выберите нужное устройство. Перенесите IP кнопкой «Использовать выбранный IP».
4. На вкладке «Прошивка» выберите профиль и BIN **приложения**, собранный для OTA этой платы.
5. Введите пароль, совпадающий с работающей прошивкой. Пустой пароль допускается.
6. Нажмите «Обновить по OTA» и дождитесь итога передачи и перезапуска.
7. Дождитесь восстановления сети, повторите поиск и проверьте версию.

«Проверить OTA-порт» подтверждает TCP-доступность. Эта кнопка не отправляет приложение и не доказывает его успешный запуск. Сообщение о принятии в staging тоже не заменяет проверку новой версии после старта.

## Обнаружение STM32 и ESP

Сканер использует запрос FLProg OTA и DNS-SD/mDNS. В 0.7.7 добавлены прямые mDNS-запросы к узлам выбранной подсети через отдельный динамический UDP-порт: это помогает, когда multicast-ответы не доходят до приложения.

- **FLProg OTA**: протокол ответил и может сообщить модель, версию и разметку памяти.
- **Arduino OTA / mDNS**: устройство объявляет Arduino OTA; ESP8266 обычно использует порт 8266.
- **Legacy**: старый FLProg-приёмник вернул `ERR!`; это предположительное обнаружение без модели.

Обнаружение ESP **не означает поддержку его прошивки этим STM32-загрузчиком**. Для ESP требуется отдельная реализация Arduino OTA. Не отправляйте STM32 BIN на ESP.

## Разметка памяти

Для проверенного FLE4D-30MT / F407VG:

| Область | Адрес / размер |
|---|---|
| Загрузчик | `0x08000000`, зарезервировано 64 KiB |
| Приложение | `0x08010000`, максимум 448 KiB |
| Staging | `0x08080000`, оставшаяся верхняя половина Flash |

У других профилей адреса и объёмы отличаются. Используйте данные профиля, а не эту таблицу для всех плат. OTA пишет staging и область приложения; область загрузчика исключена из OTA-записи. Полное стирание внешним программатором является отдельной операцией.
