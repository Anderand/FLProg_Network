# Web UI редактор в FLProg Network r14

Запустите **Редактор/FLProg_WebUI_Editor.exe** из корня комплекта или START_WEB_EDITOR.bat
из корня комплекта. Откроется http://127.0.0.1:8766/. При занятом порте:
`FLProg_WebUI_Editor.exe 18843`. Python отдельно не нужен. Переносите целиком
папку Редактор, включая _internal; один EXE отдельно не работает.

1. Создайте/откройте .flpui, выберите транспорт проекта FLProg и папку проекта вне IDE.
2. Разместите виджеты и каналы. «Проверить проект» проверяет типы, связи и пересечения.
3. «Совместимость» проверяет комплект и пути без записи файлов.
4. «Собрать пакет» создаёт библиотеки в <папка проекта>/libraries. Подходящая
   FLProg_WebUI копируется рядом; копия проекта в IDE только по отдельной галочке.
5. Импортируйте единый Web UI Start и задайте ID проекта. Таблица «Каналы FLProg»
   показывает CHANNEL и подходящие Publish/Command. Сеть/SPI остаются в FLProg.
6. В OTA-менеджере выберите .ino и внешнюю папку libraries, проверьте совместимость.

Старые пакеты один раз пересоберите из .flpui, без смены ID и связей FBD.
«Демо: уставка и busy/result» открывается одной кнопкой. Сценарии можно записать,
сохранить в JSON и повторить без ПЛК; имитация не исполняет программу FBD.
