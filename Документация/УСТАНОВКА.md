# Ручная установка r15

Скачайте полный ZIP из GitHub Releases и распакуйте целиком. Закройте FLProg
и Arduino IDE. Вручную скопируйте три папки из Библиотека — FLProg_Network,
FLProg_WebUI, Flprog_Modbus — в <IDE>/portable/sketchbook/libraries с заменой
файлов только этих библиотек. Для STM32 используйте core 3.0.0; core 2.7.1
не поддерживается. Не заменяйте RT_HW_00_BASE, Flprog_Utilites, Wire и ядро
отдельными файлами. Библиотек-установщиков/BAT установки нет.

Импортируйте нужные .ubi/.ubl из Блоки_FLProg через пользовательскую библиотеку
FLProg. Перезапустите FLProg и IDE. Для WebUI достаточно одного Start с ID;
Publish/Command подключаются по таблице CHANNEL. SPI/Ethernet задаёт FLProg.

Существующие .flpui откройте новым редактором и пересоберите пакет: он получит
паспорт совместимости и подходящий runtime. ID/каналы/FBD-связи менять не нужно.
Предпочтительно хранить проект вне IDE и передавать менеджеру папку libraries.
