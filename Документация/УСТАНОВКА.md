# Установка FLProg Network

## 1. Скачать и распаковать

Актуальный комплект — `FLProg_Network_2026-10-25_r13.zip` из [GitHub Releases](https://github.com/Anderand/FLProg_Network/releases/latest). Распакуйте его целиком; автоматический Source code ZIP содержит исходники без готовых EXE.

Распакуйте ZIP целиком в постоянную папку. Внутри верхней папки `FLProg_Network` должны находиться `Библиотека`, `Блоки_FLProg`, `Редактор`, `OTA_Менеджер`, `Примеры`, `Исходники`, `Проверки` и `Документация`.

Для проверки скачивания рядом публикуется файл `.zip.sha256`. Например, в PowerShell:

```powershell
Get-FileHash 'C:\Downloads\FLProg_Network_2026-10-25_r13.zip' -Algorithm SHA256
```

Сравните поле `Hash` со строкой из скачанного `.sha256`. После замены файла релиза контрольная сумма меняется; используйте пару файлов одного скачивания.

## Требование для STM32

**Требуется STM32 core 3.0.0** — пакет STMicroelectronics, используемый Arduino IDE/FLProg. На нём проверены FLE4D и BIN 1.0.10-LOAD. Core 2.7.1 не поддерживается: его IPAddress не содержит метода toString(). Arduino IDE 1.8.19 и STM32 core — разные версии компонентов.

Проверьте папку `<IDE>/portable/packages/STMicroelectronics/hardware/stm32/3.0.0` и путь ядра в логе компиляции. Если FLProg поставляется с 2.7.1, используйте комплект FLProg с ядром 3.0.0 или штатный порядок обновления пакета плат с сохранением пользовательских профилей. Не подменяйте отдельные файлы ядра и штатные Wire, RT_HW_00_BASE, Flprog_Utilites. Требование относится к STM32; ESP использует собственное ядро. Более новые ядра отдельно не проверены.

## 2. Скопировать три библиотеки вручную

1. Закройте FLProg и Arduino IDE.
2. Найдите реальную папку IDE вашей установки FLProg, например `C:\F-981\FLProg\ideV8`.
3. При необходимости сохраните копии трёх заменяемых библиотек вне папки `libraries`.
4. Из папки `Библиотека` скопируйте **FLProg_Network**, **FLProg_WebUI** и **Flprog_Modbus** в `<IDE>\portable\sketchbook\libraries` с заменой совпадающих файлов.
5. Откройте FLProg заново.

Проверка вложенности:

```text
ideV8/portable/sketchbook/libraries/
├── FLProg_Network/
│   ├── library.properties
│   └── src/
├── FLProg_WebUI/
│   ├── library.properties
│   └── src/
└── Flprog_Modbus/
    ├── library.properties
    └── src/
```

Папка `Библиотека` целиком в `libraries` не копируется. Дополнительного уровня `FLProg_Network/FLProg_Network` быть не должно.

`RT_HW_00_BASE` и `Flprog_Utilites` используются из штатной IDE. Они не входят в этот комплект. BAT-установщиков библиотек нет: установка выполняется вручную.

Если FLProg создал виртуальную копию на диске `Z:`, обновляйте реальную папку IDE. Перезапуск FLProg нужен для обновления виртуальной копии.

## 3. Импортировать нужные блоки

Библиотеки C++ и пользовательские блоки FLProg устанавливаются разными действиями. Копирование C++-библиотек не импортирует блоки.

1. В FLProg откройте работу с пользовательскими блоками или пользовательскими библиотеками.
2. Выберите импорт `.ubi` для отдельного блока или `.ubl` для комплекта. Название пункта зависит от версии FLProg.
3. Откройте соответствующий файл из `Блоки_FLProg`.
4. Найдите импортированный блок в пользовательской библиотеке и добавьте его в схему.

Состав и подключения описаны в [справочнике блоков](БЛОКИ.md). Для Web UI дополнительно нужен конфигуратор конкретного проекта: его создаёт редактор.

## 4. Запустить программы

- Редактор: `Редактор/FLProg_WebUI_Editor.exe` или `START_WEB_EDITOR.bat` в корне комплекта.
- Менеджер: `OTA_Менеджер/FLProg_STM32_OTA_Manager.exe` или `START_OTA_MANAGER.bat`.

Python для готовых EXE не требуется. Переносите папки программ целиком: редактору нужны DLL и ресурсы, менеджеру — профили и инструменты сборки.

## Обновление существующей установки

Сохраните свои `.flpui`, проекты FLProg и нужные настройки. Затем повторите ручное копирование трёх библиотек. Если обновлялся контракт блока, замените старый блок в схеме согласно его README. Изменение только оформления Web UI не требует повторного импорта универсальных блоков.
