## Результат

В итоговом дереве сохранены все 170 путей из upstream, из которых 165 файлов совпадают побайтно, включая низкоуровневый драйвер RMII и оба файла WiznetHardware. Сверх upstream добавлены семь файлов (включая манифест, документацию и журнал проверок). Пять существующих файлов отличаются:

| Файл | Изменение от upstream |
|---|---|
| `src/flprogNetwork.h` | Публичный FLProgRmiiInterface, флаги доступности, типизированные методы реестра. Сохранены комментарии к API RESET/SPI. |
| `src/flprogNetwork.cpp` | disconnect() вызывает остановку Wi-Fi/AP только для соответствующего режима/запущенного состояния, чтобы RMII/Wiznet не отключали отдельный Wi-Fi интерфейс. |
| `src/device/flprogNetworkDeviceRegistry.h` | Тип RMII = 3, getRmii(), existsRmii(). Значения прежних типов не изменены. |
| `keywords.txt` | Публичные RMII методы и константы. |
| `tests/check_typed_registry.py` | Дополнительные проверки RMII. |

Восстановлены upstream-исправления, которых не было в локальном архиве: управление RESET с Arduino SPI и RT_HW, проверка SPI backend и отказ от обязательной стартовой задержки, если она не назначена. Сохранены `setPinRST`, `setSpeedSPI`, явный выбор backend, изоляция RMII/Wi-Fi от SPI. Добавлены отсутствовавшие в локальном архиве upstream-файлы `docs/NETWORK_SETTERS_RU.md` и `tests/check_setters.py`. Старые отчёты о сборках сохранены в исходном виде и относятся к 14.11.2026, не к этому merge.

Дополнительные материалы RMII: `docs/RMII_STANDALONE_FLPROG_RU_2026-11-17.md`, `examples/RMII_Standalone_Network/`, `tests/check_rmii_interface.py`, `tests/check_rmii_wifi_only_profile.py`. Пересчитан `MANIFEST_SHA256.json` на весь комплект (кроме самого манифеста).

Версия в library.properties / заголовке оставлена `1.0.0-rc.6a.dev.20-ntp-timezones`, API 10006. Номер релиза и изменение API level оставлены на решение автора. Старые вызовы генератора, включая `#include "flprogEthernet.h"`, остаются допустимыми.

## Проверки 20.11.2026

Все семь скриптов `tests/check_*.py` прошли. Нативные проверки выполнялись с g++ / clang++; проверка RESET/SPI — с clang++ через адаптер аргументов Zig (профили 0, 1, 2). Для Wi-Fi-only три предупреждения об unused-функциях тестового стенда, ошибок нет. Проверено 514 уникальных ключевых слов. Журнал: `docs/MERGE_RMII_R18_TESTS_2026-11-20.txt`.

Это проверки API, реестра, отдельных фрагментов реализации, профилей и тестовых заглушек; НЕ полная компиляция Arduino, НЕ испытание Ethernet/Modbus на аппаратуре. Пользователь сообщил об успешной сборке FLProg-скетча до слияния. После merge необходимо повторить сборку реального проекта KC868-A16 и регрессию Wiznet/Wi-Fi на целевых платах. Отдельного аппаратного теста изоляции Wi-Fi при disconnect() не выполнено. Вопрос двойного обслуживания WebServer оставлен вне этого merge.
