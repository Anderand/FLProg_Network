## Форматы файлов

Инструкции, справки, отчёты и заметки по исправлениям хранятся в **Markdown (`.md`)**. Служебные TXT сохраняются: `keywords.txt` читает IDE; `BOARD_PROFILE_APPEND.txt` и `boards_ota_append.txt` содержат настройки плат. Их нельзя переименовывать в рамках оформления документации.

EXE и BIN находятся в готовом архиве раздела [Releases](https://github.com/Anderand/FLProg_Network/releases/latest). Репозиторий содержит исходники; наличие профиля и успешная компиляция сами по себе не подтверждают работу на физической плате.
