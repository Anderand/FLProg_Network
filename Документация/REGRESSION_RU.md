Последняя сборка добавляет `GET /flprog-webui/meta`, содержащий точную версию
runtime. На приведённой проверке endpoint ещё отсутствовал: это подтверждает,
что ESP использует предыдущий импортированный конфигуратор.

Командные endpoint не вызывались: это могло изменить физическое состояние
реле. Их проверяют только в согласованной безопасной схеме.

## Совместимость темы

Если `/flprog-webui/meta` уже показывает `1.0.0-20261011`, а config ещё
отдаёт fallback `#121826`, в схеме остался старый трёхпараметрический
конфигуратор. Следующая пересборка с runtime и descriptor из этой поставки
исправляет это без повторного импорта UBI.

## Обязательный порядок очной проверки

1. Импортировать новый `FLProg_WebUI_Configure_demo_controller.ubi`.
2. Импортировать `FLProg_WebUI_Universal_Blocks.ubl` и подключить каналы.
3. Скомпилировать и прошить обычным способом FLProg.
4. Открыть IP устройства в Chrome и Edge, проверить все команды.
5. После любого сбоя сохранить компиляционный лог и ответ endpoint
   `/flprog-webui/config`.
