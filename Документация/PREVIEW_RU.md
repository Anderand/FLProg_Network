# Предпросмотр без контроллера

## Быстрое демо

Нажмите **«Демо: уставка и busy/result»** в верхней панели редактора.
Одно нажатие открывает готовый проект и запускает предпросмотр.
Демо заменяет текущий открытый макет; перед переключением сохраните свой
проект. Файлы на диске при открытии демо не перезаписываются.

В демо есть уставка температуры, подтверждаемая команда «Пуск», bool-каналы
busy/result и индикатор результата. Исходный макет находится в
`projects/preview_busy_demo.flpui` рядом с редактором.

Откройте проект и нажмите **«Предпросмотр»**. Ошибки проекта нужно
исправить до запуска; пересечения не мешают просмотру.

Справа работает веб-интерфейс из тех же встроенных HTML/CSS/JS-ресурсов,
которые использует контроллер. Слева находится локальная модель каналов.
Она не подключается к ПЛК и не изменяет проект.

## Проверка значений и команд

- Задайте значение канала слева и нажмите его **«Применить»**.
  После очередного опроса значение появится справа.
- Поля и кнопки справа отправляют команды в локальную модель.
  Действуют подтверждения и состояния полей настоящего веб-интерфейса.
- Поле «Факт» слева показывает принятое моделью значение, журнал — команды.
- Можно менять и publish-каналы: это имитирует новые данные из FBD.
  Команды из веба в publish-каналы отклоняются.

## Busy и result

Для виджета должны быть заданы дополнительные связи busy/result.
При включённом **«Авто busy/result (2 секунды)»** команда устанавливает
busy=true; через две секунды busy сбрасывается, result получает true,
1 или «Выполнено» соответственно типу канала. Повторная команда во время
busy отклоняется. Это демонстрационная логика выполнения, а не программа FBD.

Для своих сценариев выключите автоматику и задавайте busy/result слева.
Если связей нет, они не создаются автоматически и не сохраняются в проекте.

## Связь и перезапуск

- Выключите **«Связь включена»**. Обмен прекращается; через пять секунд
  без свежих данных веб блокирует управление. Включите связь — интерфейс
  снова синхронизируется.
- **«Перезапустить ПЛК»** обнуляет числовые значения, сбрасывает bool,
  очищает строки, ревизию и время работы модели. Отложенные завершения
  старых команд отменяются. Интерфейс обнаруживает перезапуск при опросе.
- Закрытие и новый запуск предпросмотра создают чистую модель.

## Ограничения

Предпросмотр проверяет интерфейс, а не аппаратную часть. FBD, Ethernet,
Wi-Fi-сканер, OTA, сохранение настроек и периферия не исполняются.
Начальные значения модели — нули, false и пустые строки; реальные
начальные значения задаются программой ПЛК. Внешняя сеть и переходы по
ссылкам в предпросмотре отключены. Для окончательной проверки аппаратной
программы по-прежнему требуется контроллер.
