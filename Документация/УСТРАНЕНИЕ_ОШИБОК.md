# Устранение ошибок

Сначала сохраните полный текст ошибки и версии компонентов. Проверяйте один этап за раз: установка библиотеки → импорт блока → компиляция → запуск сети → сервис → обновление.

## Библиотеки и компиляция

| Симптом | Действие |
|---|---|
| `flprogNetwork.h` или `flprogOtaUniversalBlock.h: No such file` | Проверьте три папки библиотек в реальной IDE, наличие `src`, отсутствие лишнего уровня вложенности; перезапустите FLProg |
| Компиляция использует `Z:`, а файлы обновлены на `C:` | Перезапустите FLProg для обновления виртуальной копии; сверьте используемый путь по логу |
| Старое объявление `begin` не принимает новые аргументы | Сверьте установленную библиотеку с комплектом; проверьте, нет ли второй старой копии в другом sketchbook |
| Неверное смещение OTA / static assertion | Используйте профиль и сборку для OTA выбранной платы, а не обычный адрес приложения |
| Несколько библиотек найдено для Wire | Посмотрите, какая реально используется; само сообщение не является ошибкой сборки |
| Нет `upload.pattern` | Это ошибка конфигурации загрузки IDE; готовый корректный BIN можно записывать поддержанным способом через менеджер |

## Блоки и Web UI

| Симптом | Действие |
|---|---|
| Блок не появился | Импортируйте `.ubi` или `.ubl` в пользовательские блоки, а не только скопируйте C++-библиотеку |
| «Ошибка загрузки: controls.js», HTTP 500 | Обновите FLProg_WebUI до 1.6.3 и пересоберите прошивку: [подробное исправление](ИСПРАВЛЕНИЕ_HTTP_500.md) |
| FLProg считает блок некорректным | Сохраните сообщение и используемый `.ubi`; сверьте версию FLProg и комплект блока. Статическая корректность XML не заменяет импорт в конкретной версии |
| Редактор не открывается | Запускайте из распакованной папки со всеми DLL; проверьте порт 8766 и другую работающую копию |
| Страница показывает старые элементы после обновления | Перезагрузите вкладку без кэша; убедитесь, что запущен EXE из нового комплекта |
| Пакет создан, но не установлен | Найдите путь из итога сборки и скопируйте папку пакета в libraries своей IDE |
| Виджет не получает данные | Проверьте ID пакета, конфигуратор, тип и номер `CHANNEL`, разрешение EN и подключение переменной FBD |
| Ошибка генератора | Сохраните текст и `.flpui`; проверьте типы виджетов и каналов, уникальность ID и ограничения descriptor |

## Сеть и OTA

| Симптом | Действие |
|---|---|
| `FOUND=0` | Проверьте `NET_NUM` и наличие сетевого интерфейса в схеме |
| IP `0.0.0.0` | Проверьте SPI, CS, чип, кабель, link и DHCP. Получение IP может занимать время |
| `SUPPORTED=0` | Сверьте платформу, backend, профиль компиляции и библиотеку |
| `READY=0`, ожидание сети | Сначала добейтесь готовности Ethernet и IP |
| TCP `10061` / connection refused | На адресе не слушает выбранный порт: проверьте IP, приложение, EN и порт |
| TCP timeout | Проверьте доступность устройства, подсеть, маршрут, кабель и завершение DHCP после перезапуска |
| ESP не виден в старом менеджере | Используйте 0.7.7 или новее с прямым mDNS-поиском; проверьте выбранную IPv4-подсеть |
| Порт ESP 8266 не соответствует профилю STM32 | Это другой протокол; не отправляйте STM32 BIN на ESP |
| После передачи нет новой версии | Принятие staging не подтверждает запуск. Проверьте перезапуск, журнал UART, версию в сканере и совместимость разметки |

Не диагностируйте рабочие контроллеры отправкой тестовых прошивок или команд сброса. Для испытаний используйте отдельную согласованную плату.

## Что приложить к сообщению об ошибке

- Версии FLProg, IDE/ядра, менеджера и библиотеки.
- Точную модель МК и объём Flash, подключение Ethernet, SPI/CS и UART.
- Полный лог компиляции или операции; для старта — UART от момента сброса.
- Название профиля и имя BIN; для WebUI — ID проекта и `.flpui` без паролей.
- Что ожидалось и что произошло, повторяется ли ошибка.

Пароли, токены и личные настройки перед публикацией удаляйте из приложений к сообщению.

## IPAddress has no member named toString

При STM32 core 2.7.1 эта ошибка означает несовместимое ядро. Требуется core **3.0.0**, на котором проверен комплект. Ошибка не связана с сообщением «Несколько библиотек найдено для Wire.h». Не заменяйте Wire; проверьте версию пакета STMicroelectronics в фактическом пути компиляции. Arduino IDE 1.8.19 сама по себе версию ядра не определяет.
