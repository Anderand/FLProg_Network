# ESP-мост Universal 0.12

ESP32 — универсальный транспорт между UART ПЛК и Wi-Fi/LAN. Настройки MQTT (брокер, порт, пароль, темы) остаются только в ПЛК.

## Что изменилось

- Общий сеанс UART для WebUI и TCP-клиента ПЛК: чтение веба не сбрасывает MQTT-соединение.
- Раздельные результаты запросов, ограниченная обработка UART, без автоматического повтора команд записи.
- PLC TCP сохраняет последние принятые байты после FIN, до их прочтения приложением.
- ESP ограничивает порцию чтения до преобразования счётчика: поток 65536 байт больше не превращается в пустой.
- Буферы потока ПЛК остаются RX220/TX220; полный веб-проект загружается из Flash ПЛК.

## Обновление существующей ESP

Для проверенной ESP32 WROOM с прежней таблицей разделов используется только application BIN по адресу 0x10000. Не стирайте Flash: NVS содержит настройки сети и UART. Этот файл не является полной первичной прошивкой и не предназначен для STM32.

MQTT через ESP требует новой библиотеки FLProg_Network на ПЛК и регистрации FLProgMqttBridgeTransport. Core: NET_KIND=3, NET_NUM — номер зарегистрированного транспорта. Импортируйте Core/Publish/Subscribe из каталога MQTT Basic либо Professional. Существующая прошивка ПЛК автоматически не приобретает новый транспорт после обновления только ESP.

Подключение и API: [инструкция MQTT](../Исходники/FLProg_Bridge/docs/MQTT_BLOCKS_BRIDGE_RU.md), [протокол](../Исходники/FLProg_Bridge/PROTOCOL_RU.md), [дорожная карта](МОСТ_ДОРОЖНАЯ_КАРТА.md).

Проверки программного стенда не заменяют аппаратное испытание UART ESP↔FLE4D. SPI/RMII/LAN, реальный MQTT через UART и длительный ESP heap пока не проверены на подключённых платах.
