# FLProg_Network dev20 — финальный r18, 14.11.2026

Основа: актуальный main e68f94f + финальный комплект dev20/EIS. Метки заголовка и library.properties согласованы: 1.0.0-rc.6a.dev.20-ntp-timezones; API 10006.

Сохранены новые RT_HW session API, автоматическая фабрика, типизированный реестр и исправление OTA include. При объединении сохранён Arduino GPIO writer из main и прежний запуск без дополнительной задержки, если RESET/задержка не настраивались. Явный выбор backend имеет приоритет над автоматическим RT_HW.
