## Условия PASS

Каждая аппаратная строка PASS основана на проверке Андрея на ESP8266 NodeMCU 0.9 с библиотекой из установленной папки FLProg. Кросс-платформенные строки PASS означают только успешную контрольную компиляцию, а не аппаратную проверку. PASS не переносится автоматически на отсутствующее оборудование.
