# Передача проекта — 26.09.2026

## Текущее состояние

Рабочая библиотека установлена в FLProg portable sketchbook. Основной результат: один HTTP-сервер обслуживает Wi-Fi STA, SoftAP и два W5500; исходный FLProg-проект работает без ручного изменения generated `.ino`.

## Пользовательские аппаратные параметры теста

- ESP8266 NodeMCU 0.9.
- W5500 #1: `192.168.100.218`.
- W5500 #2: `192.168.100.219`.
- Wi-Fi STA: `192.168.100.217`.
- SoftAP использует отдельную AP-подсеть.

Не хранить и не публиковать пароли сети; они остаются только в пользовательском проекте.

## Следующий gate

Modbus TCP Slave, KaScada/W5500 с Pause=1 мс, короткий soak с AP OFF/ON ×3, TCP/UDP gate, OTA, NTP и multi-transport HTTP failover на текущей библиотеке подтверждены PASS. STA TCP/UDP подтверждены обменом; AP listeners подтверждены запуском, внешняя проверка AP-клиентом принята как PASS по согласованию с пользователем. MQTT отложен на пострелизный этап: штатного блока FLProg для него нет. RMII web gate отложен до появления оборудования. Далее: Optical Architecture Gate.

## Правило продолжения

Сначала один измеримый gate, затем запись результата в документы и новый архив. Не менять generated `.ino` вручную; исправления делать в библиотеке.
