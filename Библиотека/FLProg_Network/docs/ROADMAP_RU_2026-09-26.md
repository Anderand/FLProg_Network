## Ближайший практический блок

1. Кроссплатформенная compile-матрица: ESP32, RP2040/RP2350, STM32.
2. RMII web gate — отложен до появления RMII-оборудования.

## Транспорт и сервисы после текущего блока

1. Optical Architecture Gate: выбрать архитектуру оптического транспорта до реализации.
2. RMII web gate — отложен до появления RMII-оборудования.
2. HTTP Client/Server, MQTT, NTP, OTA — аппаратные и регрессионные проверки.
3. RMII/LAN8720: Web-интеграция; программная/compile база уже существует, аппаратная проверка остаётся отдельной.
4. Общая multi-transport политика для прикладных служб, не только для Web.
5. ESP32, RP2040/RP2350 и STM32 регрессии.

## Архитектурные и выпускные этапы

1. Optical Architecture Gate: выбрать прозрачный Ethernet PHY/media-converter либо собственный packet transport. До выбора не фиксировать PHY, скорость, кодирование или MTU.
2. RAM/IRAM/Flash оптимизация, приоритет — ESP8266.
3. Очистка примеров, документации и подготовка `.ubl`.
4. Полный регресс, RC-пакеты RU/EN/FULL, soak, режим только bugfix.
5. Выпуск v1.0.0 stable.

## Правило статуса

PASS означает воспроизводимый результат на указанной платформе и конфигурации. Старый PASS не заменяет регрессию после архитектурного изменения. Generated `.ino` вручную не редактируется: совместимость реализуется в библиотеке.
