# Локальные изменения Ethernet 1.6 · 05.11.2026

Официальное поле version в library.properties не меняется. Эта запись фиксирует локальную доработку поверх установленной версии, а не новый официальный upstream-релиз.

## Объём

Изменены три файла:

- src/hardware/flprogSpiBackend.h — существующий RT_HW-backend делегирует готовым сессиям; сохранены публичный контракт и busy-callback.
- src/hardware/flprogWiznetHardware.h — настройки задержки/RESET, uint8_t API и внутренние поля однократного запуска.
- src/hardware/flprogWiznetHardware.cpp — однократный RESET/восстановление, корректный WAIT при занятом SPI, частота без resetInit().

Добавлены:

- src/flprogRtHwEthernet.h — один optional-header. Явное подключение из скетча, готовый num-реестр, привязка backend, настройки частоты/RESET.
- 0900_Развитие/0100_Развитие_Network.md — принятые правила, наблюдения и дальнейшее упрощение.
- этот журнал изменений.

RT_HW_00_BASE не меняется. Новых SPI-драйверов, реестров, общих аппаратных статусов и функций RT_HW нет.

## Как пользоваться

```cpp
#include <flprogRtHwEthernet.h>
FLPROG_DECLARE_RT_HW_SPI_BACKEND(ethSpi0,RT_HW_Base,RT_HW_STRUCT_SPI_DEV);
FLProgWiznetInterface ethernet0(PB6,1); // Пины только этого примера платы.

void setup(){
    uint8_t ok=ethBindRtHw(0,ethernet0,ethSpi0);
    ok=ok && ethSetStartupDelay(0,500);
    ok=ok && ethSetReset(0,FLPROG_ETH_RESET_MANAGED,PD6);
    // Проверить ok. Эти вызовы не запускают SPI и не переключают RESET.
    ethernet0.setDhcp();
}
// После пользовательской «Инициализации» обслуживать ethernet0.pool().
// Частоту менять из loop между pool(): ethSetSpiSpeed(0,20000000UL).
```

Для модуля без управляемого пина: ethSetReset(0,FLPROG_ETH_RESET_NONE).
Если импульс уже выполняет профиль/приложение: ethSetReset(0,FLPROG_ETH_RESET_EXTERNAL).

MANAGED по умолчанию активен LOW, hold=2000 мкс. Полярность и длительность можно задать дополнительными аргументами. GPIO-профиль должен соответствовать плате. В RT_HW-интеграции запись пина выполняет существующий pinDigitalWrite(), а не собственный GPIO-драйвер сети.

## Существенная граница

Установка библиотеки не добавляет include/backend/привязку в заново сгенерированный FLProg-скетч. Для испытания использовать подготовленный скетч. Генератор и CDI автоматически не редактировались; их доработка — следующий этап после аппаратного подтверждения.

## Проверки и резервные копии

Протоколы, файлы до изменения, манифест SHA-256 и скетчи хранятся в комплекте проекта 0290_Установлено_Ethernet_1.6_20261105 на G и в проверенной копии на D. В библиотеке не хранится вторая исполняемая копия исходников.

Компиляция не подтверждает измеренную длительность RESET, реальный SCK или работоспособность на PLC. Сводный актуальный результат установки и сборок — 0540_Установка.json в комплекте проекта. На контроллер агент прошивку не записывает.
