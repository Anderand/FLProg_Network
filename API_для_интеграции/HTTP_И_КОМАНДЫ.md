# HTTP WebUI и подтверждения

Источник истины: [FLProgWebUiFlprogNetworkPagedHttp.h](../Библиотека/FLProg_WebUI/src/adapters/FLProgWebUiFlprogNetworkPagedHttp.h), [FLProgWebUiHttpProtocol.h](../Библиотека/FLProg_WebUI/src/FLProgWebUiHttpProtocol.h). Ниже текущий paged transport, а не обещание неизменности всех маршрутов.

| Запрос | Назначение |
|---|---|
| GET `/` | Страница WebUI |
| GET `/flprog-webui/item` | Порционная загрузка описания виджетов/страниц; параметры смотрите в handler item |
| GET `/flprog-webui/state?page=...` | Полный снимок значений страницы |
| GET `/flprog-webui/state?page=...&since=...` | Изменения относительно revision |
| POST `/flprog-webui/write?channel=...&value=...&widget=...` | Запись URL-кодированного значения; widget нужен для проверок связанных с виджетом |
| GET `/flprog-webui/scan` | Состояние сетевого сканирования |
| POST `/flprog-webui/scan/start` | Запуск сканирования, если поддерживает платформа |

Остальные зарегистрированные маршруты отдают CSS/JS; `controls.js?part=...` делит код без увеличения числа маршрутов. Полный перечень — begin() адаптера. JSON state содержит `revision`, `uptime`, `values`. При уменьшении revision/uptime после рестарта отбросьте старое подтверждение команды и получите полный снимок без since. После обрыва тоже требуется полный снимок; не отправляйте старый черновик автоматически.

Успешный приём записи: HTTP 202 и `{"queued":true}`. Проверяйте HTTP-статус и JSON, а не только открытый TCP-порт. HTTP 409 при busy запрещает повторную команду. Ошибки типов/канала и переполнение обрабатывайте как отказ; точные ветви кодов смотрите в write() и протоколе.

Уведомления: «Отправлено» означает начало HTTP-запроса; «Принято» — queued=true; «Подтверждено данными» — свежий readback или новый цикл busy/result. Старый result=true не подтверждает новую операцию. Таймаут, потеря связи и рестарт оставляют результат неизвестным без автоматического повтора. Подробные сценарии и проверка на FLE4D: [уведомления](../Документация/NOTIFICATIONS_RU.md), [код notice-*.js](../Исходники/WebUI/runtime/FLProg_WebUI/web_assets).

Проверки для интегратора: несовместимый тип, отсутствующий канал, busy=1, старый result=true, отмена подтверждения, обрыв до/после ACK, полный state после рестарта, повторная загрузка страницы. Изменения FBD на реальном оборудовании проверяйте отдельно: readback не доказывает физическое переключение выхода.
