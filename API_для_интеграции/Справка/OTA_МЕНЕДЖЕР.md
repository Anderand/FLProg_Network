# OTA-менеджер 0.7.13

Запустите OTA_Менеджер/FLProg_STM32_OTA_Manager.exe из полного архива.
Переносите всю папку с profiles и build_tools. Python отдельно не нужен.

## Проверка и компиляция

На «Плата и сборка» выберите точную плату, папку IDE, экспортированный .ino
с OTA-блоком и папку libraries проекта WebUI. Нажмите «Проверить совместимость».
Проверяются core 3.0.0, заголовки, паспорт и runtime; ошибки останавливают
компилятор, дубли показываются предупреждением. Старые пакеты пересоберите
из .flpui новым редактором. Проверка не устанавливает библиотеки и не прошивает ПЛК.
Самостоятельная проверка доступна и без включения непроверенных плат.

По умолчанию доступен проверенный FLE4D-30MT. Каталог остальных плат/профилей
показывается по отдельной галочке и не считается аппаратно проверенным.
SPI/Ethernet берутся из скетча FLProg. Windows7 отдельно не проверялась.

## Обновление

Во вкладке «Прошивка» выберите подходящий профиль, актуальный IP и свой BIN
явно через «Выбрать BIN». Профиль содержит старый проверенный пример, его
не следует принимать за последнюю прошивку вашего проекта. Проверка TCP-порта
подтверждает только доступность порта. После OTA подтвердите новую версию
в сканере и вебе. Автосброс требует соответствующей уже работающей прошивки.
Для первой установки загрузчика нужен ST-Link; при обычном OTA загрузчик
не переписывается. Приложение FLE4D для0x08010000 нельзя писать по0x08000000.

[Подробная совместимость](BUILD_COMPATIBILITY_RU.md) · [Проект вне IDE](EXTERNAL_PROJECT_RU.md).


## Главная кнопка в 0.7.13

На вкладке «Прошивка» явно выберите BIN, IP и пароль, затем большую кнопку
«Прошить по OTA». «Собрать BIN» только собирает; «Проверить OTA-порт» только
проверяет соединение. Новый пример1.0.23 находится в Примеры/FLE4D_1.0.23_WIDGETS.
