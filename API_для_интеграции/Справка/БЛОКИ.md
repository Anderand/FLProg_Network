# Блоки FLProg

Импортируйте .ubi/.ubl из Блоки_FLProg в пользовательскую библиотеку FLProg.
Для WebUI используйте один **FLProg_WebUI_Start.ubi** с параметром **ID проекта**.
Он подключает <ID_webui.h> и вызывает старт после настройки сети. Новый ID
проекта не требует отдельного вида Start. Сеть, SPI, CS и DHCP задаёт FLProg.

Publish Bool/Int/Float/Text передают фактические данные; Command принимает
команды по CHANNEL. Системные номера0–100, пользовательские101+. Таблица
«Каналы FLProg» и CHANNELS_RU.md в пакете показывают номера и связи. NEW
означает принятую новую команду, а не доказательство её физического выполнения.

После изменения макета пересоберите пакет; при том же ID блоки не заменяются.
После изменения каналов проверьте FBD-связи. OTA-блок задаёт версию прошивки,
использует сеть FLProg и подходящий профиль памяти; одного WebUI Start для OTA
недостаточно. Старые проектные Configure_<ID>.ubi больше не являются основным
способом подключения. [Start](PROFESSIONAL_START_BLOCK_RU.md) · [Каналы](CHANNEL_CONTRACT_RU.md).
