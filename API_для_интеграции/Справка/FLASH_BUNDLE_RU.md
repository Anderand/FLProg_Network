# Объединённые ресурсы из Flash

27.10.2026. Проверено на FLE4D-30MT / STM32F407VG / W5500,
проект a123, прошивка **1.0.22-BUNDLE**, адрес `192.168.100.17`.

## Изменение

Загрузчик на `/flprog-webui/controls.js?part=loader&v=...` теперь выдаёт
объединённый JavaScript, включающий CSS и 22 скрипта в прежнем порядке.
Получение всего файла завершается до его выполнения. Bootstrap запускается
один раз, данные ПЛК читаются после создания интерфейса.

Файл хранится `static const ... PROGMEM` и передаётся через существующий
`sendStreamProgmem` порциями не более 256 байт за проход. Объединённый
ресурс имеет 27922 байта исходного текста и 9612 байт gzip.
RAM-очередь HTTP остаётся 2048 байт, JSON-буфер адаптера — 1024 байта,
HTTP-клиент — один, маршрутов — 14. Буфер на весь файл не выделяется.

Большой ресурс включён только при `FLPROG_HTTP_SERVER_HAS_FLASH_STREAM`.
Для старой Network без потокового API сохраняется прежний загрузчик
с небольшими ресурсами и их проверками размера. Сборка без gzip также
выдаёт объединённый текст из Flash потоком. На аппаратуре испытана gzip-сборка.
Версия immutable-кеша вычисляется по содержимому ресурсов и объединённого
текста; обновление не использует старую версию из браузерного кеша.

## Сравнение на контроллере

Выполнено по три последовательных холодных чтения до и после OTA.
У клиента нет HTTP-кеша; каждый ответ прочитан полностью, используется
`Accept-Encoding: gzip`. Фоновые запросы встроенной вкладки на время серии
остановлены. Сравнение включает HTML, все ресурсы, две страницы метаданных,
24 описания виджетов диагностики и первый снимок данных.

| Показатель | 1.0.21-FLE4D | 1.0.22-BUNDLE |
|---|---:|---:|
| Всего запросов | 52 | 29 |
| HTML и статические ресурсы | 25 запросов | 2 запроса |
| Полный холодный проход, три опыта | 27.909 / 31.684 / 30.675 с | 15.966 / 15.389 / 14.903 с |
| Медиана полного прохода | 30.675 с | 15.389 с |
| Медиана HTML и статики | 14.829 с | 0.635 с |
| Flash по компилятору | 158832 байта | 167816 байт |
| BIN | 159316 байт | 168300 байт |
| Статическая RAM | 19392 байта | 19392 байта |
| Динамически занято по диагностике | 7304 байта | 7304 байта |

Полный проход ускорился в 1.993 раза, время сократилось на 49.83%.
Flash выросла на 8984 байта. Описания виджетов и состояние остались
динамическими отдельными ответами: 27 запросов после загрузки статики.
Их объединение — отдельное следующее улучшение. Задержка повторного TCP
соединения в этой задаче не менялась.

Это одинаковые замеры прямого HTTP-клиента. Первое открытие новой версии
во встроенном браузере показало `data-load-ms=11058`, включая чтение
описаний и первых данных после получения HTML. Старое браузерное число
5491 мс было получено при других условиях кеша: их нельзя сравнивать как
ускорение/замедление двух прошивок. Статика новой версии ещё не была
в кеше браузера. Время после OTA ожидания DHCP в сравнение загрузки не входит.
Повторное открытие той же новой версии показало 6917 мс. Это отдельный
браузерный замер с кешем; он не заменяет сравнение холодных проходов.

  скриптов, вставку одного CSS и один запуск bootstrap.

- Все блоки подтверждены, итог `OKAY`, автоматический перезапуск и версия

- Полный объединённый файл прочитан с аппаратуры и распакован; он совпал
  с исходником побайтно (LF). SHA-256:
  `af6a79211e67f471b241b1da653e78610a81b3a41f33f4ffde67630054fb928f`.
- Все ответы трёх новых полных проходов — HTTP 200. Проверены веб,
  обновление системных данных и идентификация OTA после перезапуска.
- HTTP-server `.h/.cpp` в использованных библиотеках совпадают с прежними
  по SHA-256: транспорт и размеры его буферов не менялись.
- Проверка RAM относится к размерам программы и наблюдавшимся выделениям;
