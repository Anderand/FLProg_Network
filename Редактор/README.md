# Web-редактор FLProg Network r15

Готовый EXE: [полный архив r15](https://github.com/Anderand/FLProg_Network/releases/tag/v2026.10.28-r15).
В архиве запустите FLProg_WebUI_Editor.exe, сохраняя всю папку с _internal.
[Исходники редактора](../Исходники/WebUI/editor) · [генератор и тесты](../Исходники/WebUI/tools).
Откройте .flpui, задайте ID/папку проекта, проверьте совместимость и соберите пакет.
Новые bundle/catalog требуют пересборки пакета существующего проекта.
[Общая инструкция](../Инструкция.md).
