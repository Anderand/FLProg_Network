# Web UI редактор FLProg Network — r13

[Скачать общий комплект с EXE](https://github.com/Anderand/FLProg_Network/releases/download/v2026.10.25-r13/FLProg_Network_2026-10-25_r13.zip).

1. Распакуйте весь архив.
2. Запустите Редактор/FLProg_WebUI_Editor.exe или START_WEB_EDITOR.bat из корня комплекта.
3. Откроется http://127.0.0.1:8766/. Python не нужен. Если порт занят старой копией, закройте её или задайте другой порт: `FLProg_WebUI_Editor.exe 18826`.
4. Кнопка «Демо: уставка и busy/result» открывает демонстрацию и локальный предпросмотр без ПЛК.

Переносите всю папку, включая DLL, public, runtime, tools, projects и integration. EXE находится в полном ZIP Releases; в Git хранятся [исходники](../Исходники/WebUI).

Для сборки прошивки STM32 требуется **STM32 core 3.0.0**; ядро 2.7.1 не поддерживается (IPAddress::toString). Самому EXE ядро не нужно — требование относится к компиляции скетча. Три библиотеки устанавливаются вручную; штатные библиотеки не заменяются. [Общая инструкция](../Инструкция.md).

В r13 обновлён runtime генератора: процент загрузки, ограниченные повторы GET, кеширование по хешу. HTML и данные не кешируются, команды не повторяются. [Поведение и отчёт](LOAD_RU.md). На ПЛК новая версия появляется только после пересборки/OTA, обновление EXE само его не перепрошивает.

В комплекте готовый BIN Примеры/FLE4D_1.0.10_LOAD/FLE4D_LOAD_1_0_10.bin. В менеджере выбирайте его явно. Менеджер и существующие профили не менялись.
