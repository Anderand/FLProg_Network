# Web UI редактор FLProg Network

## Скачать и запустить EXE

1. **[Скачайте общий архив r12](https://github.com/Anderand/FLProg_Network/releases/download/v2026.10.25-r12/FLProg_Network_2026-10-25_r12.zip)** из [GitHub Releases](https://github.com/Anderand/FLProg_Network/releases/latest).
2. Распакуйте весь архив в отдельную папку.
3. Откройте `Редактор` и запустите **FLProg_WebUI_Editor.exe** либо корневой `START_WEB_EDITOR.bat`.
4. Откроется браузер: http://127.0.0.1:8766/. Python для EXE не нужен.

Не выносите EXE отдельно от DLL, public, runtime и остальных файлов. EXE опубликован в архиве Releases; здесь хранятся исходники.

## Возможности r11

Проверка проекта с переходом к виджету, демо уставки и busy/result одной кнопкой, предпросмотр без ПЛК, состояния полей, синхронизация после перезапуска, группы, подтверждение команд и уведомления. Runtime поддерживает gzip и порционную выдачу из Flash. Для нового веба на ПЛК требуется пересборка прошивки; проверенный пример — 1.0.9-NOTICES для FLE4D-30MT.
