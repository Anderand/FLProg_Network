# FLProg WebUI — комплект редактора для передачи

Дата комплектации: 14.11.2026.

Запуск: `Editor/FLProg_WebUI_Editor/FLProg_WebUI_Editor.exe`. Папку `_internal` оставляйте рядом с EXE. Редактор работает локально; для запуска готовой программы Python не нужен.

## Состав

- `Editor` — EXE, собранный из включённых исходников, его ресурсы и примеры.
- `Source/flprog_webui_next` — сервер редактора, HTML/CSS/JS, генераторы, тесты, runtime, контракты интеграции, проекты и документация.
- `Libraries/FLProg_WebUI` — библиотека WebUI для установки. Пользовательские блоки находятся в её `user_blocks`.
- `Source/flprog_webui_next/specification` — инструкции и спецификации. Основная инструкция — `Source/flprog_webui_next/README_RU.md`.
- `Source/legacy_web_ui_designer` — исходный прототип 0.1 для справки; текущий редактор расположен в `Editor`.
- `Checks` — результаты проверок сборки и запуска.

## Подготовка FLProg

Установите FLProg_Network из отдельного сетевого ZIP этой передачи, затем FLProg_WebUI из `Libraries`. Сетевые исходники не дублируются в этом комплекте. Для STM32 требуется core 3.0.0; ESP8266/ESP32 используют собственные ядра.

Если библиотеки FLProg находятся не в стандартном для редактора каталоге `C:\F-981\FLProg\ideV8\portable\sketchbook\libraries`, перед запуском задайте переменную окружения `FLPROG_LIBRARIES` с путём к вашему каталогу библиотек. В примерах проектов очищены локальные пути вывода; перед сборкой выберите свою папку проекта.

## Сборка из исходников

Из `Source/flprog_webui_next` запустите `python tools/build_editor.py --output <новая_папка>`. Требуется PyInstaller; текущий EXE собран Python 3.8 / PyInstaller 6.10.0. Для запуска исходников используйте `python editor/server.py` и откройте `http://127.0.0.1:8766`.
