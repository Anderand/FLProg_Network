# Проверка комплекта r11

26 тестов Python/Node и статическая проверка runtime прошли.
Новый EXE проверен: демо, предпросмотр с уведомлениями и сборка пакета
без установки в IDE. Копии runtime в библиотеке, редакторе и исходниках совпадают.

На FLE4D: уставка, отмена, приём и подтверждение busy/result, повтор при
старом result=true, ошибка ввода и прокрутка пяти карточек. Таймаут,
HTTP-отказ, отсутствие ACK, перезапуск и восстановление проверены автотестами.
Физическое отключение Ethernet в этом испытании не выполнялось.

BIN 1.0.9-NOTICES включён без пересборки:
SHA-256 4dd7d62c6ca069cfa0a023cb2d309489e38d7e5aa69bdeeb53ddff773fa200d8.
Flash 133840, static RAM 16112; пик heap/стека отдельно не измерялся.
19 статических ресурсов проверены после gzip-распаковки, маршрутов 14.

CRC и SHA-256 каждого файла ZIP проверены. Только три библиотеки, ручная
установка. Network, менеджер, профили, блоки, Modbus и старые примеры
совпадают с r10. Git и GitHub не изменялись.
Машинный итог: RELEASE_R11_VERIFICATION.json.
