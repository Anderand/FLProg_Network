# Аппаратная проверка WebUI — FLE4D-30MT, 24.10.2026

По прямому запросу пользователя выполнено OTA-обновление 192.168.100.8.
Итоговая версия: **1.0.4-WEBUI1.7**. ST-Link и ручной сброс не использовались.
Версия, Layout 1, Flash 1024 KiB, адрес приложения 0x08010000 подтверждены FLPINFO.
BIN: 134396 байт; Flash по сборке 133912, RAM 16112 байт.

На реальном STM32 найдены и исправлены две ошибки:

- nano printf без поддержки %f выдавал пустые числа в JSON; заменено форматирование
  как дескрипторов виджетов, так и значений модели через Arduino dtostrf.
- проверка повторяющихся каналов считала текущую дополнительную связь уже обработанной;
  учтён сдвиг индекса: основной канал — 0, первая связь — 1.

Фактически проверены: автоматический перезапуск после OTA, доступность новой версии,
разбор JSON всех восьми виджетов и состояния, число 25.0, три группы,
онлайн-статус в браузере и отображение busy=false/result=false.
Команды и отключение Ethernet оставлены пользователю для проверки; физические выходы
ПЛК тестовый проект не переключает. Рабочие ESP не затрагивались.

GitHub и архив r3 не обновлялись. Перед публикацией необходимо пересобрать общий
комплект с обоими исправлениями. Исходники библиотеки и их runtime-копия исправлены.
