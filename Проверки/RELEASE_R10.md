# Проверка комплекта r10

25 тестов Python/Node и статическая проверка runtime проходят.
Пересобран EXE: проверены демо, предпросмотр, валидация и сборка пакета без установки в IDE.
Копии runtime в редакторе, библиотеке и исходниках совпадают.

На FLE4D: точные 128 КиБ и gzip, медленное чтение ~8 секунд, четыре обрыва,
восстановление после зависшего клиента и ответы OTA во время остановки HTTP.
Финальный BIN 1.0.8-STREAM без стресс-массивов включён без пересборки:
SHA-256 80758a0c42717844c093a1f7f82b233db18f7119177b83e7a1576c31f5632184.
Уставка, подтверждение команды и busy/result проверены в браузере.
Flash 131136, static RAM 16112, контекст 6120; пик heap/стека отдельно не измерялся.

При упаковке проверены CRC и SHA-256 всех файлов архива, только три библиотеки,
отсутствие штатных библиотек и установщиков. Менеджер, профили, блоки и Modbus
не менялись. Git и GitHub не изменялись. Машинный итог — RELEASE_R10_VERIFICATION.json.
