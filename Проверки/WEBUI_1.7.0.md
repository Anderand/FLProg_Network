## Ограничения

На физический контроллер прошивка не загружалась; внешние рабочие ESP не трогались.
Приём команды не подтверждает физическое выполнение; result публикует схема FBD.
Новый UI требует ручного обновления FLProg_WebUI и пересборки пакета/прошивки.
Менеджер 0.7.7, его профили и загрузчики не изменялись.

Полный манифест и проверка ZIP выполняются при запечатывании локального выпуска.

Дополнительно: EXE из полного комплекта открыл grouped_controls.flpui и создал пакет/UBI без установки в IDE. Мобильный макет групп проверен без горизонтального переполнения. Сгенерированный дескриптор также успешно скомпилирован. Тесты состояния отвергают некорректный JSON вместо ложного статуса «На связи».
