# Проверка FLProg Network r14 —27.10.2026

## Состав и программы

Только три устанавливаемые библиотеки: FLProg_Network, FLProg_WebUI,
Flprog_Modbus. Network взята из проверенного комплекта FLE4D1.0.21,
WebUI — текущий согласованный runtime с API1; Modbus сохранена изr13.
В архиве есть оба готовых EXE: Редактор/FLProg_WebUI_Editor.exe и
OTA_Менеджер/FLProg_STM32_OTA_Manager.exe0.7.9. Рядом находятся все зависимости,
профили и руководства. Установщиков библиотек, stock RT_HW_00_BASE,
Flprog_Utilites и Wire нет. Личные settings.json и кэши не включены.

## Выполненные проверки

- 83 теста и static verify выполнены из подготовленного дерева исходниковr14.
- Общая проверка перед экспортом/компиляцией: отсутствующий заголовок,
  старый runtime, повреждённый/чужой паспорт, изменённый descriptor,
  core2.7.1, несколько проектов, отсутствующая Network и неверный путь.
- В EXE редактора проверены успешный экспорт, автоматический отказ при
  старой WebUI вIDE и успешная сборка во внешнюю папку с пробелами.
- В EXE менеджера проверены отчёт скетча и предупреждения о дублях.
- Реальный скетч FLE4D с исходным профилем собран с новыми заголовками:
  Flash158832, staticRAM19392, BIN159316. Размеры не выросли. includes.cache
  подтверждает внешние wrapper/runtime. Новый C++-контракт не добавляет RAM.
- Заголовки API для Сергея сверены по SHA с библиотеками этого комплекта.
- Старые BIN в Примеры сохранены как исторические; устройство при упаковке
  не прошивалось. Нельзя принимать BIN1.0.10 за новые возможностиr14.
- Локальный ZIP проходит CRC и сравнение SHA256 каждого файла с манифестом.
  Для опубликованного архива дополнительно выполняется обратное скачивание
  и сравнение с локальным; итог фиксируется после публикации.

## Границы

Новый пакет требует паспорта совместимости. Старый .flpui нужно один раз
пересобрать новым редактором без изменения ID/CHANNEL/FBD-связей. Проверка
редактора проверяет экспорт, менеджер — прямые include скетча; вложенные
условные подключения не раскрываются. Дубли отображаются предупреждением,
окончательный выбор библиотеки подтверждается логом компилятора. Проверка
не заменяет компиляцию и аппаратные испытания. Установку вIDE выполняют
вручную либо используют внешнюю папку libraries.

Нативный hidden/show отложен пользователем. IAB не сообщал hidden=true;
проверенный synthetic event на живом FLE4D дал68.122с/0новыхstateGET,
затем полный снимок безsince200. Не выдавать это за нативный тест браузера.
Storage и выравнивание тоже отложены. Аппаратно проверен указанный FLE4D;
прочие платы и Windows7 отдельно не объявляются испытанными.
