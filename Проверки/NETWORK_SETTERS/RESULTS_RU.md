# Результаты проверки совместимости RESET и SPI

12.11.2026. Проверена библиотека из подготовленной Git-копии на основе
`main` (`2526802`), с добавлением четырёх файлов исправления. Скетч `pr1`
с исходными вызовами `setPinRST(255)` и `setSpeedSPI(20000000UL)` не изменён.

## Полная сборка

Arduino CLI 1.6.0, ESP32 core 3.3.11, FQBN `esp32:esp32:esp32s_dev_eis`,
`--jobs 0`. Библиотека выбрана явно через `--library`; фактический путь
подтверждён подробным журналом CLI.

Результат: успешно, код возврата 0. Время: **352,91 с**.
Кэш не очищался; число не является сравнением холодных сборок разных IDE.

```text
Sketch uses 1192656 bytes (90%) of program storage space. Maximum is 1310720 bytes.
Global variables use 61560 bytes (18%) of dynamic memory, leaving 266120 bytes for local variables. Maximum is 327680 bytes.
```

После компиляции выполнена только нормализация концов строк заголовка
с сохранением исходного смешанного формата и удаление пробелов в комментарии.
Исполняемый код не менялся.

## Программные проверки

Нативные тесты из `run_tests.py` прошли для UNIVERSAL, WIFI_ONLY и WIRED_ONLY.
Проверены Arduino backend и реальный шаблон RT_HW backend с имитацией
аппаратных вызовов. Настройки частоты не вызывают SPI, RESET 255 не вызывает
GPIO, смена частоты сохраняет состояние инициализации. Пройдены проверки
ошибок, занятости, времён RESET и переполнения счётчиков, перечисленные в README.

Дополнительно проверено побайтовое соответствие **2** изменённых
заголовков API-копии исходникам FLProg_Network. `git diff --check` прошёл.
Публичные тесты не содержат скетч пользователя, его настройки сети или
локальные пути разработчика.

Это проверка компиляции и программной логики. Загрузка прошивки и аппаратные
испытания W5500, RT_HW GPIO или других плат не выполнялись.
