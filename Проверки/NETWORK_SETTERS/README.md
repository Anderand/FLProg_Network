# Проверка совместимости RESET и SPI

`run_tests.py` извлекает проверяемые методы из текущих исходников библиотеки,
компилирует C++11 и запускает их на компьютере. GPIO, время и соседние части
сетевого интерфейса заменены заглушками. Используются настоящий заголовок
Wiznet-драйвера, реализация SPI-арбитра и проверяемые методы настройки.

Из корня репозитория с Python 3 и Zig в PATH:

```text
python Проверки/NETWORK_SETTERS/run_tests.py
```

Параметры `--zig`, `--library` и `--output` позволяют явно выбрать компилятор,
корень проверяемой библиотеки и каталог артефактов. По умолчанию артефакты
размещаются во временной папке и удаляются после завершения.

Проверяются профили UNIVERSAL, WIFI_ONLY и WIRED_ONLY:

- точные вызовы из `pr1`: RESET 255 и SPI 20 МГц;
- отсутствие GPIO/SPI в setters и отложенное применение;
- изменение частоты без сброса состояния, отказ при собственной SPI-блокировке;
- частота 0, изоляция Wi-Fi/RMII и запрет поздней настройки RESET;
- однократный импульс 2 мс и восстановление 500 мс, переполнение счётчиков;
- конфликт RESET с CS, недопустимый пин, прежний запуск без новых настроек.

Тесты методов не заменяют сборку полной прошивки и аппаратное испытание W5500.
Результат контрольной сборки и состав опубликованного исправления находятся
в [отчёте](RESULTS_RU.md).
