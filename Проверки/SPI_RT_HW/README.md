# Регрессия фиксированного RT_HW SPI

Компиляция C++11 и запуск на компьютере. Заглушки относятся только к этому тесту.
Команда из корня репозитория:

    zig c++ -std=c++11 -IПроверки/SPI_RT_HW/stubs -IБиблиотека/FLProg_Network/src Проверки/SPI_RT_HW/backend_test.cpp -o <временная-папка>/spi-test.exe

Запустите полученный EXE. Проверяются две шины, отдельные CS/дескрипторы,
параметры по умолчанию RT_HW, отказ отсутствующей шины, занятость без ожидания,
совместимость старого lookup API и время жизни backend при очистке интерфейса.
Для аппаратной проверки требуются отдельные W5500, SPI и RESET.
