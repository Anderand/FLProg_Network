# Проверка комплекта r9

Gzip на FLE4D: 15 ресурсов совпали после распаковки, проверены Content-Length,
Content-Encoding, Vary и согласование кодировки; OTA с автоперезапуском,
уставка 25→30.5, подтверждение команды, busy/result и счётчик 0→1.
Flash 137040→130856, статическая RAM 16112→16112; heap/стек отдельно не измерены.

Пересобран переносимый EXE; проверены демо, предпросмотр и пакет проекта.
25 автоматических тестов, статическая проверка runtime, CRC архива и SHA-256
каждого файла. Итог: RELEASE_R9_VERIFICATION.json рядом с отчётом.

Только три проектные библиотеки, ручная установка. Штатные библиотеки
не включены. Менеджер, профили, блоки, Modbus и старые примеры неизменны.
Проверенный gzip-BIN включён без перекомпиляции и совпадает по SHA-256.
Git и GitHub не изменялись.
