# Проверка общего комплекта r7

Проверены типы каналов, отсутствующие связи, пересечения, переходы к виджету,
защита сборки в браузере и API. Проверен локальный предпросмотр: каналы,
команды, подтверждение, busy/result, offline/reconnect и перезапуск.
23 автоматических теста проходят; переносимый EXE запускает предпросмотр.

При упаковке проверяются SHA-256 каждого файла ZIP, CRC, синтаксис Python,
относительные ссылки новых инструкций и неизменность остальных компонентов.
Итог машинной проверки: RELEASE_R7_VERIFICATION.json рядом с этим отчётом.

Runtime и прошивка 1.0.7 сохранены без изменений из r6. Новых аппаратных
испытаний для этого выпуска не выполнялось. Git и GitHub не изменялись.
