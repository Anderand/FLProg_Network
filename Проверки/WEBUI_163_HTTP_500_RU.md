# WebUI 1.6.3 — проверка исправления HTTP 500

Дата: 24.10.2026. Переданный случай: STM32 + W5500, ошибка загрузки controls.js.

- Воспроизведён HTTP 500 старого controls.js в локальном HTTP-стенде с лимитом 2048 байт полного ответа.
- Исправленные встроенные ресурсы загрузили две страницы и виджеты без ошибок JavaScript. Все запросы ресурсов интерфейса и данных завершились HTTP 200. Необязательный favicon на стенде вернул 404.
- Node --check: семь JavaScript-модулей без ошибок.
- Все девять статических ответов вместе с HTTP-заголовком укладываются в 2048 байт; максимальный — controls.js, 1967 байт.
- Используется 14 обработчиков при штатном лимите 14. Размер HTTP-буфера не увеличен.
- Для ресурсов добавлены static_assert с резервом заголовка 128 байт; check_http_assets.py включён в verify_release.py.
- WebUI static verification и 5 тестов генератора: PASS.
- Контрольная компиляция STM32F407/W5500: PASS, Flash 113776 байт, RAM 12628 байт. Сборка проверяет исправленный адаптер с включёнными HTTP-обработчиками.
- Контроллер пользователя не прошивался; аппаратное подтверждение после обновления его проекта ещё не получено. Рабочие ESP не использовались для испытаний.
